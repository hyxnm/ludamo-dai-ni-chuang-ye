# 求职避坑审计表

> 配套能力：`qiu-zhi-bi-keng-yu-mian-shi`（本表的操作依据）、`da-gong-qi-bu`（先确定该去哪个岗位）
> **使用规则**：先排除巨坑，再比较优劣。出现"巨坑"档直接出局，不做横向比较。

## 1. 基础信息

- **意向岗位**：
- **这家公司对应我目标行业的哪一环**：（若答不出，回到 `da-gong-qi-bu` 先选岗位）
- **岗位是"信息位"还是"体力位"**：□ 信息位（能看到定价/客户/渠道/结算） □ 体力位
- **公司背景（天眼查/企查查核验）**：
  - 注册资本 / 实缴资本：
  - 经营异常 / 法律诉讼（尤其劳动争议）：
  - 营业执照范围（是否与招聘岗位相符）：
  - 成立时间：（不足两年且无其他背书 → 标"待观察"）

## 2. 薪酬结构五问（每项都要数字）

| 问项 | 对方回答 | 是否明确 |
|---|---|---|
| 底薪 |  | □ 明确 □ 含糊 |
| 提成/绩效的计算方式 |  | □ 明确 □ 含糊 |
| 发薪日 |  | □ 明确 □ 含糊 |
| 社保缴纳基数与起始月 |  | □ 明确 □ 含糊 |
| 加班：加班费 or 调休 |  | □ 明确 □ 含糊 |

- **判停**：任一项含糊 → 中风险；两项以上含糊 → 巨坑信号
- **硬门**：要求先交钱（培训费/押金/设备费）→ **立即终止**

## 3. 陷阱识别

- □ 招聘文案含"零门槛 + 高薪资 + 包吃住"组合 → 打问号
- □ 独立信源评价（员工评价/离职率讨论）已查：来源 ______
- □ 岗位描述与实际沟通内容一致

## 4. 简历自查（不造假，要放大）

- [ ] 每条经历都是"动词 + 数量 + 场景 + 结果"
- [ ] 每条数字都可验证（被追问时说得出细节）
- [ ] 已删掉与目标岗位无关的内容
- [ ] 单页，且只突出本岗位需要的特质（行政岗写细心，不写别的）
- [ ] **没有任何一条需要虚构**（有 → 改写成"目前不了解，但愿意学"）

## 5. 面试准备（实话说策略）

- **我的 3 个真实短板 + 可兑现说法**：
  1. ______ → "目前不了解，但愿意学"
  2. ______
  3. ______
- **内向者的正面表述**：承认内向 + 补"细心、有耐心"（可验证）
- **必问收尾**：结果反馈周期是多久？

## 6. 最终评级

- [ ] **稳健**：四项核心指标（薪资透明度 / 社保基数 / 加班逻辑 / 舆论）均明确，符合逆袭底座，可尝试
- [ ] **中风险**：存在模糊项，面试需追问后再定
- [ ] **巨坑**：皮包公司 / 杀猪盘 / 重资产套路 / 需先交钱 → **坚决不去**

**若所有机会都是巨坑档** → 结论是"继续找"，不是"挑一个相对不差的"。
