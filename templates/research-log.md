## 5. 标的摸底记录（刺客式调研 `ci-ke-shi-diao-yan`）

> **用法**：一次只摸 1 家，同一赛道至少摸 3 家才能下结论。只记对方说了什么、报了多少钱，**不记推测**。摸完转 `bi-keng-you-xian` 拆致命点。

### 5.1 接触前：先写下要拿的 3 个数字

| 标的名称 | 数字① 真实成交价（不是标价） | 数字② 交付周期 | 数字③ 成本下限（可推断时） | 各自的获取动作 |
|---|---|---|---|---|
|  |  |  |  |  |

- 三个数凑不出来（客单价过低、无交付环节）→ 标的不值得调研，直接做最小实验体
- 尚未选定行业 → 先回到第 1 节（看广告倒推），本表不负责选方向

### 5.2 摸底采集（每家填一张）

- **接触方式与状态**：加联系方式 / 进社群 / 留资 → 对方是否进入主动跟进 □是 □否
- **公开痕迹**：更新频率 □活号 □摆设；真实成交痕迹 □有 □无；成立时长 ______
- **成交流程（让对方描述，不是下结论）**：付款后第一步做什么 → ______
- **三层价格**：标价 ______ ／ 成交价（优惠/活动）______ ／ 底价（批量·长期·一次付清）______
- **施压与危险信号**：□"今天不定就没了" □只谈收益、拒绝描述交付步骤 □**要求先付钱才给任何信息（→ 立即停止）**
