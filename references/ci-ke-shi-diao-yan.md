# 刺客式调研（以买家身份摸透一个具体标的）

## R — 原文 (Reading)

> 刺客式调研：不空想，靠调研找真相。最好的项目在广告里。
> 动作：加微信、看朋友圈、套话术、摸价格、踩坑点。全程伪装客户。

— 《鲁大魔·全能逆袭智库》logic/methodology.md 心法 1、SKILL.md §2「项目拆解模式」

> **来源说明**：出自技能包 B 的归纳文本，非 A 包原有 141 条口播切片转写。

## I — 方法论骨架 (Interpretation)

本包此前有两种"调研"，但**都不是本卡**：

- `kan-guang-gao`（看广告倒推）回答"**进哪个行业**"——从广告的投放持续性判断谁在赚钱，全程不接触对方。
- `da-gong-qi-bu`（打工起步法）回答"**这个行业内部怎么运转**"——以真实雇员身份长期带薪摸流程。

本卡回答第三种问题：你手上**已经有一个具体的标的**（一个项目、一个对手、一个上游供应商、一个加盟机会），要用买家的身份在付钱之前把它摸透——它的真实成本、成交路径、话术和坑在哪。

三块拼起来：

1. **以买家身份进入**：项目的关键信息（真实成交价、交付条件、售后底线）只存在于交易入口，公开渠道拿不到。你不买，对方就不会把成交逻辑讲完整。
2. **逐层加码**：加联系方式 → 看公开痕迹（更新频率、内容类型、真实成交反馈） → 套话术（让对方把成交逻辑讲出来） → 摸价格（拿到底价与成交价，而不是标价） → 踩坑点（问退换、售后、交付失败怎么办）。
3. **产出是一页数字**，不是结论。本卡只采集，不拆致命点——拆致命点是 `bi-keng-you-xian` 的事。

**为什么值得单独成卡**：v1.1 蒸馏时它被判定"与 `kan-guang-gao` 重合"而未成卡。本次复核认为两者契约不同——看广告是**被动观察公开信号**（零接触成本、信息浅、面向行业），本卡是**主动以买家身份接触**（有接触成本、信息深、面向具体标的）。本包此前没有任何一张卡覆盖"怎么摸清一个具体项目"。

## A1 — 书中的应用 (Past Application)

### 案例 1：广告是标的的入口（methodology.md 心法 1）
- **问题**：想找一个能做的项目，但不知道从哪找。
- **方法论的使用**：主张"最好的项目在广告里"——持续投放本身就是盈利信号；从这条广告出发去加联系方式，走完买家路径。
- **结论**：广告提供的是**标的清单**，不是答案；答案要靠走一遍交易流程才能拿到。
- **结果**：把"找项目"从浏览改成一次有产出的接触。

### 案例 2：只有以客户身份才能测出的服务密度（biography.md「3 分钟回复」）
- **问题**：校园墙项目的竞争力在哪，看介绍看不出来。
- **方法论的使用**："3 分钟回复"这类服务标准，只有真的以客户身份提一次需求、掐一次表才能测出来；对方自己讲的响应时间和实际响应时间通常是两个数。
- **结论**：服务类项目的差异存在于**响应体验**里，不在宣传材料里。
- **结果**：调研动作里必须包含"实际体验一次交付"。

> **诚实标注**：来源包**没有给出任何一次完整调研的原始记录**，也没有带结果的应用案例。以上两条是本包从来源包的相邻材料（心法 1 + biography 关键数）复原的示例，不是被验证过的调研案例。证据强度记为「主张级 + 规则级」。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 看到一个加盟/代理/课程/项目，付钱前想知道真实成本与成交流程。
2. 想做某个生意，但不知道同行到底怎么定价、怎么谈单。
3. 拿到了供应商报价，怀疑不是底价。
4. 想进某个行业，但暂时找不到可以打工的公司（`da-gong-qi-bu` 走不通时的替代路径）。
5. 已经被某个项目说动，担心是坑，需要在掏钱前拿到反证。

### 语言信号 (用户的话里出现这些就应激活)

- "这个项目靠谱吗，我该怎么查？" / "How do I vet this?"
- "我想做 XX，但不知道同行怎么赚钱"
- "怎么摸清楚一个行业的底价？"
- "加盟前能做点什么调查？"
- "他这个报价是不是高了？"
- "我加了对方微信，接下来该问什么？"

### 与相邻 skill 的区分（关键：避免抢调用）

- 与 `kan-guang-gao`（看广告倒推）的区别：**序列上本卡在其后**。看广告解决"哪个行业在赚钱"（零接触、公开信号）；本卡解决"这个具体标的到底怎么回事"（有接触、私有信息）。用户问"我该做哪个行业"→ 看广告；问"这家/这个项目值不值得"→ 本卡。
- 与 `da-gong-qi-bu`（打工起步法）的区别：打工是**长期、真实雇员身份、带薪**摸内部流程，信息最深但周期以月计且要求对方招人；本卡是**短期、买家身份、自费时间**摸外部交易面，信息浅一层但几天能跑完。能打工就打工（信息更真），打不了工就用本卡。
- 与 `bi-keng-you-xian`（避坑优先法）的区别：**本卡采集，`bi-keng-you-xian` 拆解**。本卡的产出（价格底线、成交话术、售后条件）是避坑卡拆致命点的输入。用户问"怎么查"→ 本卡；问"这个项目有什么坑"→ 避坑卡。
- 与 `zui-xiao-shi-yan-ti`（最小实验体）的区别：调研是实验**之前**的低成本信息采集；摸完再决定实验体做多大。不要把"去调研"当成"已经在试"——调研不产生收入信号，只产生信息。
- 与 `xing-jia-bi-yu-gong-ying-lian`（性价比与供应链）的区别：本卡摸到的是**别人的**价格结构；定价卡决定**自己的**定价。

## E — 可执行步骤 (Execution)

1. **锁定标的，写下要拿的 3 个数字**
   - 做法：在开始接触前写下必须拿到的三个数——真实成交价（不是标价）、交付周期、成本下限（若可推断）。
   - 完成标准：三个数写在纸上，且每个都有明确的获取动作。
   - 判停条件：若标的小到连三个数都凑不出来（客单价过低、无交付环节）→ 不值得调研，直接做最小实验体。

2. **以买家身份建立接触**
   - 做法：加联系方式、进社群、留资，让对方进入销售流程。
   - 完成标准：已进入对方的成交流程，能收到对方的主动跟进。
   - 判停条件：**需要虚构公司主体、伪造资质、或假签意向合同才能继续 → 硬停**（见 B 段硬门 1、2）。身份可以真实，购买意图可以保留，但主体不能虚构。

3. **观察公开痕迹**
   - 做法：看朋友圈/动态/评价——更新频率、内容构成（是晒成交还是只发广告）、是否有带细节的真实反馈。
   - 完成标准：能说出"这个号是活的还是摆设""有没有真实成交痕迹"。
   - 判停条件：若完全没有成交痕迹且成立时间短于 3 个月 → 标为高风险，仍可继续（信息本身有价值），但不投入任何钱。

4. **让对方把成交逻辑讲出来（套话术）**
   - 做法：不问"你这个能不能赚钱"，问"我这种情况的客户一般怎么开始""付款后第一步做什么""做不出来你们管不管"。让对方描述流程，而不是下结论。
   - 完成标准：拿到一条完整的"客户从付款到交付"的流程描述。
   - 判停条件：若对方只谈收益、拒绝描述交付步骤 → 这本身就是结论。

5. **摸价格结构**
   - 做法：分三层问——标价、成交价（有什么优惠/活动）、底价（批量/长期/一次性付清能不能再谈）。
   - 完成标准：拿到至少两个层级的价格差。
   - 判停条件：若对方在价格上反复施压"今天不定就没了" → 记为典型的成交施压信号，不是价格信号。

6. **踩坑点：问失败时怎么办**
   - 做法：问退换条件、售后范围、交付失败的赔偿或补救、有没有做失败的客户。
   - 完成标准：拿到至少一条"做不成时怎么处理"的明确说法。
   - 判停条件：**若对方要求先付钱才能给任何这些信息 → 立即停止**，这正是本卡要识别的坑本身。

7. **交叉验证 3 家，然后交给避坑卡**
   - 做法：同一赛道至少摸 3 家（数量下限借用 `bi-keng-you-xian`），把采集结果写成一页，转 `bi-keng-you-xian` 拆致命点。
   - 完成标准：一页纸，含三家可比的价格区间、交付承诺、售后条件。
   - 判停条件：只摸了 1 家就下结论 → 无效，单家可能是表演。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户还没选定行业**：先用 `kan-guang-gao`，本卡不负责选方向。
- **想学的是行业内部运转流程**：用 `da-gong-qi-bu`，买家身份看不到供应链与内部协作。
- **已经有真实交易历史要复盘**：用 `bi-keng-you-xian`，不需要再采集。
- **标的涉及证券、金融产品、特许经营、医疗器械等持牌领域**：本卡的摸底方法不适用，转专业人士与官方披露渠道。
- **需要的是法律意义上的尽职调查**：本卡是个人低成本版本，不能替代有责任边界的尽调。

### 合规硬门（不得越过）

1. **不虚构法人主体**——不伪造公司名、营业执照、资质证明去接触对方。
2. **不签订任何虚假合同或意向书**——询价可以，落款不行。
3. **不以调研为名骗取商业秘密**——可以问成交逻辑与公开报价，**不可以**索取对方的内部成本表、客户名单、进货渠道、技术资料。
4. **不偷拍偷录、不侵犯隐私**——录音录像须遵守所在地法律，且不得用于敲诈、传播或商业诋毁。
5. **不恶意占用对方资源**——询价后不下单是正常的商业行为，但不得组织多人反复骚扰同一家。

> 来源包原文表述为"**全程伪装客户**"。本卡将其限定为"**保留购买意图**"：不主动纠正对方的买家假设是可以的，虚构身份与签约不可以。这是与来源包原文本的实质性差异，理由见下方盲点。

### 作者（来源包）自身的盲点

- **"全程伪装客户"表述过强**：伪装主体去谈合同、拿报价，在司法实践中可能构成欺诈或缔约过失。本卡因此把"伪装"收窄为"保留购买意图"。
- **"套话术"没有商业秘密边界**：来源包未区分"问成交逻辑"（可以）与"套取成本表、客户名单"（不可以）。这是本卡主动补的硬门。
- **未给样本量**：单家摸底极可能被刻意表演误导（销售流程本来就是设计给买家看的）。本卡补上"3 家交叉验证"，是对来源包最实质的一处补强。
- **未计时间成本**：摸底是纯投入、无收入信号。标的太小或赛道太窄时不值得做，应直接进 `zui-xiao-shi-yan-ti`。
- **假设对方会说实话**：销售流程中的价格与承诺带有成交目的，摸到的"底价"是对方的报价策略，不等于真实成本。

### 容易混淆的邻近方法论

- **神秘顾客（mystery shopping）**：企业委托的合规质检，有授权、有流程、有报告责任；本卡是个人自发的，无授权，不能声称在做质检。
- **竞品分析**：基于公开信息的分析；本卡涉及主动接触，法律与伦理边界不同。
- **尽职调查（DD）**：专业机构执行，有法律责任边界；本卡是个人低成本版本，结论不可用于投资举证。
