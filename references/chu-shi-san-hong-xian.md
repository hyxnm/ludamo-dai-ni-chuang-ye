# 处世三红线（亲人 / 朋友 / 合伙人）

## R — 原文 (Reading)

> 亲人红线：真心+分寸。报喜不报忧，不把负面情绪传给家人。用"买衣服、带吃饭"的实在事代替创业大道理。守住边界，自己的选择自己扛。
>
> 朋友红线：真诚+隔离。金钱是情谊的杀手。不向朋友借钱，不借钱给朋友（除非生死关头，且做好钱不要了的心理准备）。朋友分知己（互助）与泛交（礼貌）。不炫耀，不攀比。
>
> 合伙人红线：规则+底线。先小人后君子。必须明确：①权责划分 ②分红规则 ③退出机制。坚持决策权唯一。对背叛、摆烂零容忍，果断止损。

— 《鲁大魔·全能逆袭智库》logic/methodology.md「处世与关系三红线」／logic/sub_skills/relationships.md

## I — 方法论骨架 (Interpretation)

这是一套**关系风险的隔离协议**，处理的是 A 包 13 张卡完全没有覆盖的一个域：你和具体的人之间怎么相处。

三条红线的共同结构是「**先切边界，再谈感情**」，但每条要隔离的东西不同：

1. **亲人：隔离情绪。** 家人不是军师。你要隔离的是"负面情绪的转嫁"——把创业的压力、焦虑、不确定性丢给他们，他们既无法帮你解决，还要替你承受。替代动作是**用实在事代替大道理**：买衣服、带吃饭、干家务。判据很硬：你想跟父母解释你的商业逻辑时，改成做一件他们能直接感受到的事。同时边界是双向的——父母让你找安稳工作"可以听，但不用从"；救急可以帮，纵容挥霍要拒绝。
2. **朋友：隔离金钱。** 唯一规则是**不与朋友发生借贷**。理由是金钱会把"知己/泛交"两层关系压成一层：借钱之后，互助变成追讨，礼貌变成尴尬。例外只有生死之灾，且默认这笔钱回不来。配套的是"不炫耀、不攀比"——富贵了默默努力，张扬只会招来嫉妒和借钱请求。
3. **合伙人：隔离模糊。** 这一条最像合同，也最容易被跳过。三条必修课必须在**谈感情之前**成文：谁干技术谁干运营（权责）、按什么比例多久分一次（分红）、怎么散伙（退出）。外加一条**决策权唯一**——共同决策等于无人负责。最后是零容忍清单：背叛（卷钱、私接项目、泄密）与摆烂（消极怠工），触碰任一条即止损，不念旧情。

**三条的共同判据**：一段关系如果在让你"更敢做事"，边界是对的；如果它在消耗你的决策能量，边界已经被突破了。

## A1 — 书中的应用 (Past Application)

### 案例 1：合伙人红线的反面印证（来源包金句）
- **问题**：合伙人关系破裂时的典型结局。
- **方法论的使用**：来源包给的是一条成文红线而不是故事——"兄弟是兄弟，合伙是合伙。混为一谈，最后既丢了兄弟，又毁了项目。"
- **结论**：合伙关系失效的根因不是利益分配不均，而是**一开始没把规则从感情里切出来**。
- **结果**：把"散伙"从道德事件降级为流程事件——退出机制提前说死，散伙时不用谈判。

### 案例 2：亲人红线的行为替换（relationships.md）
- **问题**：创业者想让家人理解自己的选择，反复解释商业逻辑，家人反复劝他找稳定工作，双方都疲惫。
- **方法论的使用**：不做说服，改做实在事——买件衣服、带去吃顿饭、主动干家务；同时"尊重家人的认知水平，他们只是想让你稳当点，这没错。你做成了，他们自然就信了"。
- **结论**：家人的认可靠结果获得，不靠论证获得。
- **结果**：把一场无解的沟通战，换成一件当天可完成的具体动作。

> **诚实标注**：以上两条来自来源包的规则文本与金句，来源包**未给出带结果的应用案例**（不像 A 包的能力卡有连麦粉丝的前后对照）。因此本卡 A1 的证据强度记为「规则级」而非「案例级」。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 朋友/亲戚开口借钱，或自己想向朋友借钱周转。
2. 有人拉他合伙，关系不错但没谈过权责、分红、退出。
3. 合伙已经出问题：对方摆烂、私接项目、想撤资，他在纠结要不要撕破脸。
4. 创业压力大，跟家人反复争吵，或内疚于"没时间陪家里"。
5. 赚到钱之后不知道该不该在朋友圈、老同学面前说。

### 语言信号 (用户的话里出现这些就应激活)

- "朋友找我借钱，借不借？" / "Should I lend money to a friend?"
- "发小拉我一起干，要不要合伙？" / "My friend wants to start a business with me"
- "合伙人不出力/私下接单，我该怎么办？"
- "我爸妈不理解我在做什么" / "家里人劝我找个安稳工作"
- "赚了点钱，要不要跟家里/朋友说？"

### 与相邻 skill 的区分

- 与 `chuang-ye-liu-bu`（创业六步）的区别：六步第④步只回答"要不要找合伙人、找来干什么"；本卡回答"找到之后规则怎么定、出问题怎么止损"。用户问"该不该合伙"→ 六步；问"合伙协议怎么写/他摆烂了怎么办"→ 本卡。
- 与 `fan-mo-shi-zi-jian`（五特征自检）的区别：五特征诊断**自己的语言与行为习惯**；本卡处理**与他人的边界**。用户问"我是不是有问题"→ 五特征；问"他/他们这样对我怎么办"→ 本卡。
- 与 `ni-xi-jue-xing`（逆袭觉醒）的区别：觉醒处理**内在情绪**（迷茫、自我怀疑）；本卡处理**外部关系**。诉苦"家里人不理解"→ 本卡；诉苦"我是不是不行"→ 觉醒。

## E — 可执行步骤 (Execution)

1. **先判定这是哪一条红线**
   - 做法：把用户的问题归入亲人 / 朋友 / 合伙人三类之一。
   - 完成标准：能说出"这是 X 红线的问题"。
   - 判停条件：若同时涉及两条（如"发小借钱又想合伙"），先处理**金钱隔离**，再处理合伙规则——顺序不能反。

2. **金钱隔离（朋友线）**
   - 做法：默认不借、不借入。若必须是生死之灾，先把金额改写成"能承受全损的数字"，并把这笔钱在心里划为已支出。
   - 完成标准：给出一个明确的答复用语（不解释、不道歉、不评价对方）。
   - 判停条件：若对方以关系施压（"你不借就是不够朋友"），这正是规则要防的情形，按预设答复执行。

3. **实在事替换（亲人线）**
   - 做法：停止解释商业逻辑，改列 3 件本周内能做的具体事（买东西、吃饭、干家务、陪看病）。
   - 完成标准：列出 3 件事并已经做了 1 件。
   - 判停条件：若家人提出的是**实质性反对**（要你掏钱、要你放弃一个明确的机会），升级为协商议题，不再是情绪问题。

4. **合伙三必修课（合伙人线）**
   - 做法：在投入第一笔钱/第一个月之前，把三项写成文字——①权责划分（谁对哪个交付物负责）②分红规则（比例 + 周期 + 是否留存）③退出机制（怎么算账、多久内退出、竞业如何约定）。外加一句"最终拍板人是谁"。
   - 完成标准：四项都能用一句话说清，且**对方已看过并同意**。
   - 判停条件：若对方拒绝落到文字，视为红线未建立，不建议开始。

5. **设零容忍清单与止损动作**
   - 做法：写下两类触发即止损的行为——背叛（卷钱、私接项目、泄密）、摆烂（连续消极怠工）。为每类预设一个具体动作（暂停付款、收回账号权限、启动退出条款）。
   - 完成标准：两类行为 + 对应动作都写清。
   - 判停条件：**不要因为"已经投入很多"而延后止损**——沉没成本是这条红线最常见的破口。

6. **事后复盘边界是否被突破**
   - 做法：一个月后回看——这段关系是让你更敢做事，还是在持续消耗你的决策能量。
   - 完成标准：给出"继续 / 收紧 / 退出"的唯一结论。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **涉及具体法律文书**：合伙协议、股权结构、竞业条款需要律师与持牌专业人士，本卡只给"该谈哪几条"，不给条款文本。
- **涉及家暴、控制型关系、精神健康问题**：超出方法论范围，应转介专业机构。
- **用户问的是融资/股权设计**（投资人、期权池、估值）：那是公司治理，不是本卡的"合伙人三必修课"。
- **用"金钱隔离"推卸真实义务**：已有的法定扶养、赡养义务不因本卡而免除。

### 作者（来源包）自身的盲点

- **规则化过度**：三条红线是作者个人经验的归纳，没有论证"借钱给朋友一定伤感情"——现实中也有健康的借贷关系。本卡把它当作**默认策略**而不是物理定律。
- **"报喜不报忧"有代价**：长期单向报喜会让创业者在真正需要支持时失去可得的社会支持。若用户已出现持续失眠、情绪崩溃，应优先建议寻求专业帮助，而不是让他"自己扛"。
- **零容忍清单偏硬**：摆烂有时源于分工不清或能力不匹配，而非态度问题。止损前应先确认是否属于第 4 步的权责未写清。
- **来源包没有提供失败案例**：只有规则没有反例，说服力来自作者的权威而非证据，引用时应标明这一点。

### 容易混淆的邻近方法论

- **股权设计 / 股东协议**：解决法律与税务结构；本卡解决合作前的规则共识与止损触发。
- **非暴力沟通（NVC）**：解决表达与倾听技巧；本卡直接给出隔离规则，不谈沟通技巧。
- **边界感（boundaries）心理学概念**：通用心理学术语；本卡是具体的、带止损动作的创业场景版本。
