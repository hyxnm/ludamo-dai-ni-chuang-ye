# 创业六步流程与出场顺序（不可跳步）

## R — 原文 (Reading)

> 首先第一个，我们要确定好行业…我们还要在这个行业生态里面，找到一个具象化的产品…对于，需要这个产品和服务的人群进行一个调研…当你调研了这个需求，发现，哎，这个项目我可以做，这个时候我们要做什么，你找人啊…找合伙人…第四步把产品做出来…才进入到市场的运营的推广，第六步可能是我们说做这个，收服务，做这个二次讲话。

> 这六步，我发现它有什么，有规律，有出场顺序，第一步你都没做完，你他妈聊第二步，今天都干嘛，你第一步都没做，你聊那么多干嘛…六步，每一步都重要。

> 挖掘需求，调研需求，和你是不是，打工的，是不是，创业的，没有任何关系…挖掘需求不需要花钱的，调研需求也不需要花钱的。

— 鲁大魔，010 创业的流程，满满的干货（2026-09-12，7分32秒）／053 创业的流程满满的干货（2026-07-31，7分32秒，同内容重发）

## I — 方法论骨架 (Interpretation)

这是全书最像"标准作业程序"的一条能力，也是被反复重发的一条（010 与 053 同内容）。

**六步依次是：**

1. **确定行业** — 先落在一个行业上（卖卫生巾、卖奶茶，都是不同行业）。
2. **在行业生态里定位一个具象化的产品/服务** — 行业太大，必须垂直落到一个具体的东西上（保健品 → 落到针灸/按摩/情绪用品其中之一）。
3. **调研需求** — 目标人群的年龄段、共识、需求频率、以及竞争对手是否难搞。主播特别提醒：如果你小区周围已经有好几家同类型的店，"你进去，你就傻子了"。
4. **找合伙人 / 分配职责** — 有钱就找员工，没钱就找合伙人共担风险与资金，然后磨合。
5. **做出产品/服务** — 真正开始交付。
6. **市场运营推广 + 二次增长** — 走到这一步才能看到商业模式是否走通。

**这条方法论真正的价值不在步骤本身，而在"出场顺序"这个约束。**

主播的比喻非常直白：第一步还没做完就聊第二步，"叔叔阿姨把你生下来了，你在床上滚拿，你屎都没吃够呢，你还想去，还去想着走路"。所以他给的不是清单，而是**否决条件**——顺序不对，讨论后面所有步骤都是无效的。

配套的两条强推论：

- **前三步不需要花钱，也与是否在打工无关**。这直接反驳了"我在上班所以不能创业"这种自我设限。
- **六步都重要，没有哪一步可以替代另一步**。有粉丝问"能不能用行业大佬替代找合伙人这一步"，主播的回答是"这个世界是有秩序的，没有哪个点是动力哪个点"。

## A1 — 书中的应用 (Past Application)

### 案例 1：俄罗斯跨境电商的连麦（010）
- **问题**：一位粉丝说"我最近了解过俄罗斯跨境电商，不知道值不值得做"，并表示"只是大概了解"。
- **方法论的使用**：主播直接指出"你他妈的大概了解一下，你就给我耍流氓了"，然后用六步检验——他连第一步（确定行业）和第二步（落到具象产品）都没有真的完成，第三步（需求调研）更谈不上。因此"值不值得做"这个问题本身不成立。
- **结论**：不能跳过第一、二步去问第五步的可行性。
- **结果**：主播顺势给出了一个可执行起点——"下次好好再准备一下"，即从第①②③步开始补。

### 案例 2：把"找大佬"替换成"找合伙人"的提问（010）
- **问题**：粉丝问"找合伙人的那一步能不能替换成连接上一个行业的大佬"。
- **方法论的使用**：主播重申六步有出场顺序、每一步都不可替代，且强调"第一步你都没做完，你他妈聊第二步"。
- **结论**：步骤之间存在结构依赖，不能互相替代或用资源捷径跳跃。
- **结果**：明确否决"用资源替代步骤"的思路。

### 案例 3：限制酸奶品牌老板的连麦（015）
- **问题**：一位做限制酸奶的老板，自有技术、品牌、加盟、直营店，SOP 都齐了，但"没有事儿干"，年营业额与去年持平，问要不要做团队、怎么提升自己。
- **方法论的使用**：主播没有接他的问题，而是指出他缺的是**增长计划**——"你现在没有增长计划，就不要跟他个人成长，什么个人乱七八糟的东西"。并给出一个可画的框架：渠道、选址、招人、供应链、运营。
- **结论**：卡在中后段的时候，缺的往往是框架而不是步骤；但前提是前段的行业与产品定位已经清楚。
- **结果**：把"要不要做团队"的抽象提问，换成"先画增长框架再填充"的具体动作。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 打算创业/开展新业务，方案已经想了不少，但感觉哪里不对，说不清。
2. 有人拉你合伙、投资，或者让你一起开一家店，你需要在投钱前做判断。
3. 已经在做一门生意，但增长卡住，不知道该补哪一块。
4. 手上有多个想法在并行考虑（A 项目、B 方向、C 风口），需要排序或砍掉一些。
5. 反复问"这个项目能不能做"，但答不出到底卖什么、卖给谁。

### 语言信号 (用户的话里出现这些就应激活)

- "这个项目能不能做？" / "Is this project worth doing?"
- "我想创业做 XX，你觉得行不行？"
- "朋友拉我一起开店/做项目，我该不该投钱？"
- "我做 XX 行业，现在增长卡住了" 
- "我在上班，是不是不能创业？"（强信号）
- "第一步该做什么？" / "Where do I even start?"

### 与相邻 skill 的区分

- 与 `xu-qiu-dao-tui`（需求倒推）的区别：需求倒推是**第③步所用的推理方法**（从需求往下推产品与动作）；本能力是**覆盖全程的顺序框架**。用户问"先做什么"→ 本能力；问"需求怎么找"→ 需求倒推。
- 与 `zui-xiao-shi-yan-ti`（最小实验体）的区别：最小实验体是**每一步的规模配置工具**；本能力是**步骤与顺序**。两者组合使用，但触发不同：用户问"该不该做/先做哪步"→ 本能力；问"做多大/投多少"→ 最小实验体。
- 与 `da-gong-qi-bu`（打工起步）的区别：打工起步是**没资源时执行第①②③步的现实路径**；本能力是流程全貌。用户问"怎么进去"→ 打工起步。
- 与 `di-er-zeng-zhang-qu-xian`（第二增长曲线）的区别：后者专门处理**第⑥步之后的增长结构**问题；本能力管从头到尾的顺序。

## E — 可执行步骤 (Execution)

1. **确认用户的真实问题落在哪一步**
   - 做法：把用户的话映射到六步。普通提问通常是"能不能做"（其实是在问第⑤步的结果），此时要反向定位他实际停在哪一步。
   - 完成标准：说出一句"你现在实际卡在第 N 步"。

2. **从头逐项验证第①②③步（不花钱的三步）**
   - 第①步：行业是什么？——要求能说出行业名。
   - 第②步：在这个行业里，你做哪一个**具象化**的产品/服务？——要求一句话说清"我卖什么"。
   - 第③步：需求侧——目标人群的年龄段、共识、需求频率、以及 1 公里内/同赛道竞品的数量。
   - 完成标准：三步都能答出具体内容（不是"大概了解"）。
   - 判停条件：**任何一步答不出，立即停止讨论后续步骤**，输出"先补第 N 步"的唯一动作。这是硬门。

3. **第④步：找合伙人或员工**
   - 做法：有钱找员工，没钱找合伙人共担风险与资金。明确分工而不是泛泛"一起干"。
   - 完成标准：每个角色能说出**具体交付物**。
   - 判停条件：若用户试图用"行业大佬/资源"替代这一步，明确否决。

4. **第⑤步：做出产品/服务**
   - 做法：把第②步的具象产品交付出来。此处配合 `zui-xiao-shi-yan-ti` 把规模压到最小。
   - 完成标准：有真实客户接触过你的交付物。

5. **第⑥步：运营推广与二次增长**
   - 做法：跑市场运营，观察商业模式是否走通；随后规划第二次增长（承 `di-er-zeng-zhang-qu-xian`）。
   - 完成标准：能说出复购情况与下一步增长方向。

6. **输出"唯一当前动作"**
   - 做法：在六步中标记当前所处位置，只给**一个**下一步动作，不给清单。
   - 完成标准：用户能复述"我明天要做的唯一一件事是 ___"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **纯职业选择问题**（该不该跳槽、考公还是打工）：那是 `sheng-cun-ji-neng` / `ci-zhi-jue-ce-yu-zhi` 的范围，套六步会答非所问。
- **已是成熟企业、问题在组织结构或资本运作**：六步是**从零到一**的框架，不覆盖规模化治理。
- **用户已在交付阶段且有稳定收入**：此时反复回到第①②③步会造成"永远在验证、永远不放大"。
- **窗口期极短的套利机会**：六步需要时间，赶不上一夜之间的机会（但主播本人会反对这类机会，见下）。

### 作者在书中警告的失败模式

- **跳过第一步直接聊后面的步骤**（ce03）：找合伙人、找大佬之前，需求验证还没做。
- **以为了解流程就能创业**（ce06）：003 真实路径里说"你就觉得自己能做到了，早着呢…上去你就死"。
- **一上来就做整个生态链**（ce04）。
- **病急乱投医 / 拉熟人补自信**（ce05）：第④步的合伙人是为分工而找，不是为壮胆而找。
- **盲目总结成口号**（ce26）：026 里粉丝把一整套系统化方法总结成"慢慢来"，主播明确纠正"重心是你们要积累管理方法、专业知识、渠道拓展方法"。
- **空谈项目、追逐热点概念**（ce27）：没有具象业务就想做 web3 这类新概念，是第①步未完成的典型。

### 作者的盲点 / 时代局限

- **"六步"过于线性**：真实创业中第⑤步的交付常会反过来改写第②步的产品定义，迭代是常态；主播的线性表述会低估回环。
- **第③步的"需求调研"缺方法论细节**：他只说"不花钱"，没给出调研的质量判据（样本多大、怎么判断是真实需求还是礼貌性反馈）。
- **对"竞争对手很多就傻子了"的判断偏静态**：竞争优势可以来自差异化定位，不必然是"不进场"。
- **隐含前提是消费/服务业**：这套六步对研发驱动型、平台型、内容型创业的适配度明显更低。
- **未讨论"六步全对仍失败"的情形**：运气、周期、政策在框架之外。

### 容易混淆的邻近方法论

- **精益画布 / 商业模式画布**：静态描述商业要素；本能力强调**顺序**与不可跳步。
- **设计思维（Design Thinking）**：从共情到原型，也有顺序，但重心在创意发散；本能力重心在顺序约束。
- **产品生命周期**：讲产品随时间的演变；本能力讲从零开始的动作次序。
