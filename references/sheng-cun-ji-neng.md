# 生存技能优先（技能的判定标准是能否换到钱）

## R — 原文 (Reading)

> 一定要去学习一个生存技能…每一个人的生存技能，学习的方式，都是通过自己对于社会的判断，去了解到一些行业，觉得这个行业的生存技能能够转化成物质价值。

> 你吃饭吃饱了，你在这行业里面积累这些人事，人脉，这些朋友，同事…A 屌毛会运营，B 屌毛会选品，C 屌毛会投流，D 屌毛可以做统筹，你们这四个屌毛加在一起，不就组成了一个最小的实验团队吗？

> 兄弟们一定要学一个生存技能，这是能保证你生存下限。有了生存技能以后，那我们第二步该干什么？我们该拥有学习的是管理能力。

> 没有资源、没有能力、没有这个行业的理解…你死的概率百分之一百。

— 鲁大魔，036 给年轻人的建议（2026-08-13，10分43秒）／129 以前太不懂事，把钱造没了，也欠了一屁股债（2026-06-14，2分2秒）／050 小镇青年创业指南（2026-08-04，3分24秒）

## I — 方法论骨架 (Interpretation)

鲁大魔把"技能"从一种学历式的资格，重新定义为**一个可验证的经济事实**：能不能换到钱。

这不是修辞。它的判定非常硬——你把动作做出来，有人付钱，就是技能；没人付钱，就只是知识。所以"我学完了"不构成技能，"我靠它赚到了第一笔钱"才构成。这个标准把大量"看似在准备"的行为（读课、考证、看教程）直接筛掉。

在这个标准之上，这条方法论给出一个明确的**次序**：

1. **先有生存技能**——它的作用是保命、托底、保证下限。没有它，你所有关于创业的想法都建立在空气上，主播原话是"死的概率百分之百"。
2. **再有管理能力**——技能能换钱之后，第二步才是学支配他人的劳动（抽成、外包、带团队），这一级才涉及"提升上限"。

对没有方向的人，他给的找技能方法也很具体：**去看广告**——持续投放的广告背后一定有一个真实盈利的生意，这个生意里就有对应的岗位与技能（详见 `kan-guang-gao`）。找到后就去那个行业里工作、学习，让技能在换钱的过程中长出来。

还有一条重要的推论：**生存技能是社会协作的入场券**。四个各有技能的人（运营、选品、投流、统筹）凑在一起就是最小创业团队，而且不需要工资——因为技能本身让他们能各自活下来。没有技能的人组队只是凑人数。

## A1 — 书中的应用 (Past Application)

### 案例 1：给年轻人的四条建议（036）
- **问题**：大量刚毕业的年轻人反复问"我该干什么"。
- **方法论的使用**：主播放弃逐个给建议，直接给出四条可执行的内容，其中第四条是"一定要去学习一个生存技能"，并配了获取路径：天天去平台看广告，看持续投放的广告 → 那个行业一定赚钱 → 进这个行业里去学习、找工作。
- **结论**：找技能不是靠自我探索，是靠外部信号（广告投放的持续性）来定位。
- **结果**：同时给出了"吃饱饭 → 积累人脉 → 四人组队"的完整台阶。

### 案例 2：给"负债/失业"粉丝的翻身路径（c30）
- **问题**：一位负债且失业的粉丝，希望知道怎么最快翻身。
- **方法论的使用**：先确认他有没有一项能换钱的技能。没有 → 那就先用"看广告 + 四屌毛组队"的最小模型起步，而不是先想办法弄钱。
- **结论**：负债状态下更不能靠资金周转，唯一可行的是把技能变出来。
- **结果**：给出一个不依赖资金的起步方案。

### 案例 3：以"月入一万"证明技能已成立（105，辞掉编制）
- **问题**：粉丝想辞掉编制去创业，但不确定自己行不行。
- **方法论的使用**：让他在职期间用 AI 接单（PPT、标书代写、简历优化）做矩阵账号获客，把副业跑到月入一万。月入一万＝线上变现能力可迁移的证明，也就是"技能已成立"。
- **结论**：技能是否成立，必须用一个**收入数字**来判定，而不是用"我觉得我可以"。
- **结果**：把辞职这种情绪化决策转成了可验证的阈值实验（详见 `ci-zhi-jue-ce-yu-zhi`）。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 被问"我不知道该学什么"，或在多个学习方向之间摇摆不定（考公/考证/学编程/学剪辑/开店）。
2. 想创业或做副业，但手里没有任何可变现的技能，纠结要不要先"赌一把"。
3. 已经学了很多（课程、证书、理论）却还是赚不到钱，怀疑自己学的东西没用。
4. 父母/朋友建议先考个稳定资格，自己想走别的路，需要判断依据。
5. 想组合团队/找合伙人，但不确定该找什么样的人（找有技能的还是找有钱/有资源的）。

### 语言信号 (用户的话里出现这些就应激活)

- "我不知道该学什么" / "I don't know what skill to learn"
- "我想创业，但没什么技能，能不能先干起来？"
- "我学了很多东西但赚不到钱"
- "该不该考证 / 考公 / 读研？"
- "我想找个合伙人一起做，该找什么样的？"

### 与相邻 skill 的区分

- 与 `kan-guang-gao`（看广告倒推）的区别：`kan-guang-gao` 解决**"往哪个方向找技能"**（定位问题）；本能力解决**"什么叫技能、该按什么次序走"**（定义与次序问题）。二者是上下游：先用广告定方向，再用本能力判定是否成立。
- 与 `da-gong-qi-bu`（打工起步）的区别：打工起步是**获取技能的方式**；本能力是**判定技能是否已获得的标准**。用户问"我去哪学"→ 打工起步；用户问"我算不算学会了"→ 本能力。
- 与 `ci-zhi-jue-ce-yu-zhi`（辞职阈值）的区别：本能力给的是"技能已成立"的定义，辞职阈值给的是"可以辞职"的判定线。前者是能力判据，后者是决策判据，常组合使用。

## E — 可执行步骤 (Execution)

1. **先清算现有资产**（不是钱，是技能）
   - 做法：让用户列出过去 3 年所有"别人付过钱或明确愿意付钱"的能力项——包括兼职、帮朋友干活、接过的单、岗位上真正被依赖的那件事。
   - 完成标准：产出一张清单；如果清单为空，直接进入步骤 2；如果不为空，跳到步骤 3。

2. **用"广告扫描"定位候选行业（承接 `kan-guang-gao`）**
   - 做法：连续 7 天记录刷到的广告，挑出**反复出现**的 5 类；对每类写下它的岗位构成。
   - 完成标准：得到 ≥3 个具体岗位名称（如"投放素材剪辑""私域客服""选品助理"），而不是"电商行业"这种粒度。
   - 判停条件：如果用户已有明确的行业目标，跳过此步直接进步骤 3。

3. **把技能送入换钱测试**
   - 做法：选一个候选技能，在**不花大钱**的前提下找真实买家——熟人单、低价单、平台接单、原岗位内加活。要求是真实成交，不是模拟。
   - 完成标准：收到第一笔真实付款（金额不限）。
   - 判停条件：30 天内收不到任何一笔钱 → 判定"这还不是技能"，回到步骤 2 换一个候选。

4. **用收入确认技能成立**
   - 做法：把第一笔钱放大到可持续（连续两周有单、或单笔可复制）。此处不要追求月入一万（那是 `ci-zhi-jue-ce-yu-zhi` 的阈值），只要能证明"可重复成交"。
   - 完成标准：能说出"我做什么、卖给谁、收多少钱"三句话，且已重复过至少 3 次。

5. **进入第二级（管理能力），并明确反对的顺序**
   - 做法：只有在上一步成立后才谈支配他人劳动（外包、抽成、带团队）。同时明确否决两条捷径：先借钱创业、先花钱买"方法"。
   - 完成标准：输出一条清晰的当前阶段结论 + 一条被否决的动作。

6. **组队时只找有技能的人**（若用户问的是找合伙人）
   - 做法：按"运营 / 选品 / 投流 / 统筹"之类的职能分工筛选，要求每人自带一项已验证的技能。
   - 完成标准：能说清每个候选人在团队里**具体交付什么**，而不是"他有资源"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户已有成熟技能、只是在纠结要不要换赛道**：此时该用 `ci-zhi-jue-ce-yu-zhi`，本能力会误导他"再从头学一个技能"。
- **用户问的是具体的行业选择或岗位细节**：那属于 `kan-guang-gao` / `da-gong-qi-bu` 的范围。
- **纯知识性问题**（"什么是投流"）：不需要启动本能力。
- **用户处在必须立刻有收入的状态**（断粮）：本能力的"先补技能"节奏可能来不及，应先解决现金流（哪怕是低门槛工作），再谈技能。

### 作者在书中警告的失败模式

- **什么都不懂就盲目创业**（ce13）：主播原话是"死的概率百分之一百"，且点明"我不是让你们这些屌毛傻逼组队创业，我是让你们有技能的屌毛去创业"。
- **把准备当成行动的前提**（ce20）："先学好了再去工作"——这是拖延的伪装，技能必须在换钱的过程中长出来。
- **用低门槛兼职替代技能积累**（ce22）：把送外卖/跑腿当作长期出路，其收入被算法设定上限，不产生可积累的市场价值。
- **拿资源替代能力**（ce15/ce18）：以为有人脉、有资源就能成，忽视"资源方只与有承接能力的合作方交换"。

### 作者的盲点 / 时代局限

- **"换到钱＝技能"的标准对高门槛领域不友好**：律师、医生、科研等领域的技能需数年才能产生第一笔收入，用此标准会误判为"不是技能"。
- **隐性前提是市场仍有大量低门槛变现位**：这套路径依赖平台经济与灵活就业的规模。当平台红利退潮、供给过剩时，同样技能的第一笔钱可能更难拿到。
- **"生存技能"与"爱好"的边界被过度硬化**：主播把不能换钱的爱好整体贬低，但长期看，很多技能的变现是滞后的。
- **对"看广告定方向"的过度信任**：广告持续投放只证明投放方有钱，不证明该岗位对新人友好或行业在扩张（详见 `kan-guang-gao` 的边界）。

### 容易混淆的邻近方法论

- **"先就业再择业"**：只讲先后，不给技能判定标准；本能力给了可验证的判据（能否换钱）。
- **"一万小时定律"**：讲投入时长；本能力讲产出验证。二者结合才完整——投入必须被换钱验证。
- **"能力圈"**：讲自知边界；本能力讲如何把边界内的能力变成收入。
