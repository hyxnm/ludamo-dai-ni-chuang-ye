# 资源优先级（时间 + 体力 + 方法 ≫ 钱）

## R — 原文 (Reading)

> 你去创业，需要的是你的时间和你付出的体力劳动，以及你在做这件事情过程中慢慢去学习的方法，拼的是这三个核心点，而不是用钱去做事情…钱是我们在遇到问题以后，最没有办法的办法，是最后一个办法，解决问题靠的是时间、体力、方法，钱是最后一个办法。

> 所以这个时候，你他妈没有资格，跟我说，你是不是打工的，还是创业的，你什么家庭的小店，还没到哪一步。

> 兄弟们一定要学一个生存技能，这是能保证你生存下限。有了生存技能以后，那我们第二步该干什么？我们该拥有学习的是管理能力。

— 鲁大魔，032 鲁大魔真心建议（2026-08-15，4分0秒）／135 鲁大魔真心建议（2026-06-10，4分0秒，同内容）／010 创业的流程

## I — 方法论骨架 (Interpretation)

这条能力给的是一个**资源排序**，而不是资源清单。

**顺序是：时间 > 体力 > 方法 > 钱。** 其中"钱"被明确定义为"解决问题最没有办法的办法、最后一个办法"。

为什么这个排序反直觉？因为多数人把"启动资金"当作第一道门槛——没钱就不能开始。主播的立场正相反：钱的作用被限定在**已经用尽时间、体力、方法之后**仍无法突破的具体卡点上。推论是一串禁令：

- 不要花钱买资料（方法只能在做事中长出，买来的是信息）；
- 不要花钱认识"大哥"（时间与体力换认知，比买关系更可靠）；
- 不要借钱/贷款去创业（借钱是把不可逆资源押上，见 `zui-xiao-shi-yan-ti` 的硬门）。

与之配套的是一个**自检结构**（在不同章节被反复以"三问"的形式使用）：做任何事前问自己三件事——我是否愿意付出体力、是否愿意付出时间、是否愿意学并应用方法。三问全否，则问题不在外部条件（钱、出身、家庭），而在自身投入结构。

再往下，它连着一条财富获取的级差：第一级出卖时间体力（必经，真正积累的是能力不是钱）→ 第二级支配他人劳动力 → 第三级管理能力与资本运作。**第一级虽低级但不可跳过。**

## A1 — 书中的应用 (Past Application)

### 案例 1：小镇青年的资源盘点（050）
- **问题**：家里没资源、没人脉、没资金的青年问怎么起步。
- **方法论的使用**：主播指出"牛马屌丝最大的问题是资源受限，但这个资源不代表钱，不代表人脉，这个资源代表的很多时候是你的工作方法和你的行业知识储备"，然后把他们的真实优势明确为"那个时间，是那个体力，是你那个非常非常小的…就那几万块钱"。
- **结论**：资源定义被重写——工作方法与行业知识才是稀缺资源，钱排在后面。
- **结果**：直接推出"去做最小模型"的动作。

### 案例 2：四个屌毛组队（036）
- **问题**：没有启动资金的年轻人怎么开始创业。
- **方法论的使用**：用"每天啃馒头、不领工资"的方式把资金需求压到接近零，靠四个人各自的时间与技能置换。
- **结论**：创业的钱大部分花在养人上，所以"不领工资"就能把资金门槛抹掉。
- **结果**：给出一个不依赖外部融资的组队模型。

### 案例 3：把"没时间/没体力"当筛选条件（012）
- **问题**：很多人说想做但做不到。
- **方法论的使用**：主播反过来说，真正决定成败的是"愿不愿意付出体力劳动，愿不愿意付出时间，愿不愿意去学一些方法"——三问即是筛选器。
- **结论**：三问全否则问题在自身，不在条件。
- **结果**：把"我条件不够"的抱怨，换成了一张可自查的投入清单。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 在纠结"要不要报课 / 买资料 / 花钱请人教"。
2. 觉得"没有启动资金所以做不了"，把资金当作第一障碍。
3. 在考虑借钱、贷款、加杠杆来启动项目。
4. 想花钱"认识大哥/进圈层"，认为关系可以替代积累。
5. 想评估自己是否真的"条件不允许"。

### 语言信号 (用户的话里出现这些就应激活)

- "要不要报个课/买个训练营？" / "Should I pay for a course?"
- "我没钱所以做不了"
- "要不要借钱/贷款试试？"
- "要不要花钱认识一些圈里的人？"
- "我条件不够"

### 与相邻 skill 的区分

- 与 `zui-xiao-shi-yan-ti`（最小实验体）的区别：本能力回答**"该不该花钱"**；最小实验体回答**"如果要做，规模定多大"**。用户问"要不要投钱"→ 本能力；问"投多少"→ 最小实验体。
- 与 `sheng-cun-ji-neng`（生存技能优先）的区别：本能力讲**别先投钱**（资源观）；生存技能讲**先有技能**（能力观）。二者是同一立场（先投入自己而非资金）的两个面。
- 与 `chuang-ye-liu-bu`（创业六步）的区别：六步里第①②③步"不需要花钱"的判断依据就来自本能力，但本能力本身不管顺序。

## E — 可执行步骤 (Execution)

1. **把当前方案里的资源投入分类清点**
   - 做法：列出为了推进这件事，你打算投入的每一项资源，并标注属于"时间 / 体力 / 方法 / 钱"哪一类。
   - 完成标准：产出四类清单，其中"钱"的那一栏能说出具体金额。

2. **对"钱"那一栏逐项追问：能不能用前三类替代？**
   - 做法：对每一笔拟支出的钱，问"这笔钱解决的是什么问题？时间、体力或方法能不能解决它？"
   - 完成标准：每一笔支出都被判定为"可替代"或"卡点"。
   - 判停条件：若某项判定为"卡点"（前三类都用尽仍无法突破），保留该笔支出；否则删除。

3. **做三问自检**
   - 做法：问用户——① 我愿意为这件事付出体力吗？② 我愿意付出时间（多长）吗？③ 我愿意学并应用方法吗？
   - 完成标准：三问逐一回答。若三个"否"，输出"问题不在条件，在投入结构"，并终止资源讨论。

4. **重排动作清单**
   - 做法：把删掉的钱类动作用前三类动作替换（如：不报课 → 去同行打工；不买资料 → 每天做一条广告分析；不请顾问 → 自己跑 20 户客户）。
   - 完成标准：产出一份**不含任何大额支出**的动作清单。

5. **为真正的卡点预留资金（如果有）**
   - 做法：把资金写成"允许我失败 N 次的时间"，而不是"学费"。设一个明确的动用条件（"只有在 X 情况下才花这笔钱"）。
   - 完成标准：资金有明确用途与触发条件，而不是"备着随时花"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **已经确认存在真实卡点且只能用钱解决**：如必须购买的资质、设备、原材料、医疗/法律专业服务。此时"钱是最后一个办法"已经成立，正是该用钱的时候。
- **用户问的是"投多少钱做多大实验"**：属于 `zui-xiao-shi-yan-ti`。
- **纯消费决策**（要不要买这个包）：与创业资源无关。
- **用户已拥有充裕资金且时间成本极高**：此时用钱买时间（雇人、外包）可能是更优解，本能力会造成误导。

### 作者在书中警告的失败模式

- **借钱/贷款/加杠杆去创业试错**（ce12）：用不可逆资源承担可避免的风险。
- **用"资源"当护身符**（ce18）：以为有人脉资源就能成。
- **什么都不懂就盲目创业**（ce13）：把钱当作能补上能力的缺口。
- **把准备当行动的前提**（ce20）：花钱买"准备"。

### 作者的盲点 / 时代局限

- **"钱是最后一个办法"在某些行业明显不成立**：制造业、零售、医疗、金融等重资产或强资质行业，资金是第一门槛而非最后办法。
- **忽视时间的机会成本**：对一个时薪很高的人，用时间硬扛可能比花钱更贵。"时间比钱便宜"是一个隐含假设，主播从未论证。
- **对"花钱买关系"的一刀切否定**：在部分行业，正规的顾问/中介服务确有价值。
- **金句化风险**：这句话极容易被压缩成"别花钱、穷也要干"的口号，从而鼓励在明显该投入的地方硬扛。

### 容易混淆的邻近方法论

- **"省钱思维"**：讲节省；本能力讲**排序**（不是少花钱，而是把钱放在正确的位置）。
- **"杠杆思维"**：讲放大；本能力讲不依赖外部杠杆。
- **"投资自己"**：讲成长投入；本能力把"投资自己"具体化为投入时间与体力，而非购买课程。
