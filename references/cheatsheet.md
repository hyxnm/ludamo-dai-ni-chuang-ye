# 决策规则速查 — 鲁大魔 · 视频口播文案合集

| 能力 | 一句话规则 |
|---|---|
| 逻辑思维链（数据→秩序→逻辑→决策→工具） | 决策不是灵感，是数据积累到秩序再到判断的长链条——数据层为零时任何决策都是臆断 |
| 生存技能优先（技能的判定标准是能否换到钱） | 技能的判定标准只有一个——能否换到钱；换不到钱的是知识，不是技能 |
| 打工起步法（先去同行那里打工，把流程摸熟再自己干） | 想干哪一行，先去同行那里打工把工作流程摸熟——用就业替代调研，还是带薪的 |
| 最小实验体（风险不可规避，只能靠缩小实验体降低） | 风险不能规避只能降低；降低的唯一杠杆是缩小实验体——实验体越小，风险越小 |
| 创业六步流程与出场顺序（不可跳步） | 创业六步有严格出场顺序，第一步没做完就不要聊第二步——跳步是必死的 |
| 换不到钱的人的五特征自检 | 情感叙事、宏大叙事、无技能、不主动索引信息、信命运——命中两条以上，问题不在努力而在方向 |
| 看广告倒推（找行业 / 找岗位 / 找项目） | 连续看广告并拆解——长期投放的一定赚钱，广告里藏着产品、人群、渠道和岗位 |
| 资源优先级（时间 + 体力 + 方法 ≫ 钱） | 时间 > 体力 > 方法 > 钱；钱是解决问题最没有办法的办法，是最后一个办法 |
| 四个基本点（显性 / 具象化 / 可量化指标 / 可执行） | 任何目标要落地必须同时满足：看得见、脑中有画面、有数字指标、当下能力够得着 |
| 需求倒推法（从需求向下推演，而非从风口向上猜） | 别从风口往上猜，从需求往下推——一直推到「加谁的联系方式」这一步才算完 |
| 辞职/转型决策阈值（先跑通月入一万再辞） | 别问「该不该辞职」，先在职把副业跑到月入一万——赚钱能力证明了再辞职 |
| 第二增长曲线与生态位选择 | 第一曲线卷到毛利见底时，出路不是降价，是围绕同一批用户长出利润结构不同的第二条线 |
| 性价比与供应链/定价三角 | 性价比＝性（功能性+实用性）与价（定价+利润策略）的权重对比；广告费只是产品力不足的代价 |
| **v1.1** 处世三红线（亲人/朋友/合伙人） | 朋友金钱隔离；亲人报喜不报忧、用实在事代替大道理；合伙人先定权责·分红·退出，决策权唯一，背叛摆烂零容忍 |
| **v1.1** 求职避坑与面试实战 | 先穿透公司资质，再拷问底薪+提成+绩效+发薪日+社保五问项；简历不造假只放大；面试说实话；稳健/中风险/巨坑三档先排除巨坑 |
| **v1.1** 避坑优先法 | 先看前辈怎么死的——强制拆够 3 个失败案例，拆到结构性致命点，再映射回自己的方案；输出顺序永远是先坑后利 |
| **v1.1** 流量匹配法则 | 泛流量做广告打赏，精准流量做高客单培训；错配时换变现或换流量，**绝不用加大投流来弥补** |
| **v1.1** 人才优先与区域围剿 | 人才比业务重要；在区域内把某职能的人列到可数再逐个建立关系；把用户转成销售（单层、无入门费） |
| **v1.1** 李鬼矩阵 ⚠️ | 原始打法（注册近似品牌截流）有商标与不正当竞争风险，**不作为方案**；合法做法＝自有矩阵 + 品类词覆盖 + 差异化定位；被仿冒时走平台投诉与证据保全 |
| **v1.1** 区域聚焦与最小切口 | 避开一线卷王深耕三四线掌握定价权；打碎产业链，只干「离开大平台也能独立运行」且「高利润」的那一环 |
| **v1.1** 逆袭觉醒 ⚠️ | 迷茫先做一件今天能完成的小事；失败拆出一个结构性致命点；短板换算成投入量或换路径；质疑就停止解释；参照尺度是从搬砖到做公司 8 年 |
| **v1.2** 刺客式调研 | 摸透一个具体标的要以买家身份走一遍：加联系方式 → 看公开痕迹 → 让对方讲出成交逻辑 → 摸标价/成交价/底价三层 → 问「做不成怎么办」；至少摸 3 家交叉验证；意图可保留、主体不可虚构 |
| **v1.2** 工具化沉淀 ⚠️ | 判定一项能力能否脱离你的时间：写不出「输入→步骤→输出」就停；3 次交付步骤重合度 <70% 就停；人肉成交不足 10 次先回去跑通；载体按模板→SOP→脚本→产品逐级来，不要跳级 |
