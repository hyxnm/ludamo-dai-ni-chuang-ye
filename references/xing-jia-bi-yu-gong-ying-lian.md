# 性价比与供应链定价三角

## R — 原文 (Reading)

> 性价比指的是什么?产品的功能性、产品的实用性。对吧?这叫性。什么叫价?就是价格。产品定价、利润策略。对吧?产品的功能性加上价格去做对比,这个东西的权重在消费者心中的权重到底占多少?这叫性价比。
>
> 很多人误以为,我这个产品一定要投广告,广告团队赚的就是你产品力不行的钱。什么叫产品力不行?你的产品能力没问题,但是你定价过高,广告就是赚这部分的钱。电商赚的是什么钱?电商赚的是他妈的手续费的钱,它是两套逻辑。
>
> —— 视频 009《工厂供应链思维,都是智慧,好好看好好学》(38分53秒)

> 如果这个工厂是我的,我的生产成本是不是变成 240 了?我在定价上面的时候,你随便卖,我做的跟你一样,我比你便宜 60 块钱,你怎么说?我的定价永远比你便宜 60 块钱。……如果我产品有核心竞争力,在市场有最低定价权,我一定会把流量给你买到死。
>
> —— 视频 009(同上)

## I — 方法论骨架 (Interpretation)

把"性价比"从一个含混的感觉词,拆成**可计算的两轴 + 一个前置条件**:

**两轴:**
- **性 = 功能性 + 实用性。** 不是品牌、不是故事、不是颜值,就是这东西**能不能用、好不好用**。
- **价 = 定价 + 利润策略。** 不是"标价"这么简单,而是你打算用什么利润结构去打市场(薄利走量 / 高毛利走少)。

**判定方式:** 把"性"和"价"放在一起比较,看**两者在消费者心中的权重占比**。这个权重不是固定的——它由**市场阶段**决定。主播的判断是:在当前"所有人都在过紧日子"的存量环境里,中位人群看的是**性价比而不是 IP 属性**,而且"IP 在极致低价面前没有意义"。

**前置条件(最硬的一条):供应链能力决定你有没有定价权。** 主播用椅子举例:同样的成品,工厂不是你的,成本 300;工厂是你的,成本变 240。于是"我定价永远比你便宜 60 块钱"——这 60 块不是营销技巧,是**供应链结构带来的物理差**。有了这个差,才有定价权;有定价权,才敢说"我一定会把流量给你买到死"。所以三角的排序是:**供应链能力 → 定价权 → 性价比竞争胜出**。

**反过来看广告:** "广告团队赚的就是你产品力不行的钱"——如果你要靠投广告才能卖动,说明你的**产品定价过高**或产品力不足。这是把广告费当成了产品力缺陷的付费补偿。电商与广告是**两套逻辑**:电商抽手续费(靠极致性价比吃量),广告卖流量(靠产品力不足吃差价)。

## A1 — 书中的应用 (Past Application)

### 案例 1：大兵(电竞椅)竞争判断（视频 009）
- **问题**：听众问大兵的竞争对手是不是傲风。
- **方法论的使用**：主播纠正——大兵真正的竞争对手不是头部品牌,而是"**和我们一样的小屌丝**",因为这类后来者会持续涌入做低价(599 / 1999 的复刻)。由此推出广告费"ROI 达到 100 倍也没有用",因为**最终胜负取决于产品定价**。
- **结论**：胜负在手定价权，不在投流。
- **结果**：预警价格战一开打,资金储备要以**对手的资金量**为参照,而不是自己的绝对数字。

### 案例 2：神仙水定价思想实验（视频 009）
- **问题**：品牌溢价能不能扛住价格战。
- **方法论的使用**：主播用"把神仙水定到 100 块钱"来验证性价比轴的支配力——如果性(功能性)相同而价被打到极低,消费者不会为品牌溢价买单。
- **结论**：用来反驳"品牌/IP 能扛住价格战"的说法。
- **结果**：明确性价比轴在存量环境中的支配地位。

### 案例 3：佛山家具(孙耀)渠道链路案例（视频 009）
- **问题**：孙耀算低端还是中端？
- **方法论的使用**：听众把孙耀归为低端,主播反驳——看客单价(全屋二三十万)应算中端,其优势来自"**商业模式把渠道链路缩短了**",即供应链/渠道结构决定了成本与定价,而非品牌定位决定。并借此指出对方"对定价完全没有概念":20 万 × 10% 毛利 = 2 万利润,1000 块 × 30% 毛利 = 300 块利润,**毛利率与单笔利润量级必须分开算**。
- **结论**：看定价要看链路与量级，不看标签。
- **结果**：形成"性/价拆解 + 供应链成本差 + 定价权"的完整算法。

### 案例 4：郑凯集团收上游天然气矿（视频 009）
- **问题**：为什么收上游矿源后能卖更高客单价。
- **方法论的使用**：收了上游矿源后价格可以比同行低,给农夫山泉、可口可乐做瓶子当年只有 5 个点利润,但"我们上来的时候可以卖到三万五万的客单价"。主播把它拉回自己的框架:**不是用户和渠道变了,是产品的信息强度决定的**——大众消费品好坏肉眼能分辨(所以打价格),专业品在没使用前无法分辨、科普成本极高(所以打信任与合规壁垒)。
- **结论**：品类的"可分辨性"决定打价格还是打信任。
- **结果**：把定价问题转成"品类信息强度"的判断。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 定价决策——"这个产品该定多少钱"。
2. 要不要投广告——"卖不动,是不是该加大投流"。
3. 竞对降价——"同行比我便宜,跟不跟"。
4. 判断市场阶段——"现在该打品牌还是打价格"。
5. 自建供应链 vs 代工——"要不要自建工厂/拿上游"。
6. 判断别人的价格战——"他为什么能一直卖这么便宜"。

- "现在该打品牌还是打价格"

### 与相邻 skill 的区分

- 与 `di-er-zeng-zhang-qu-xian` 的区别:那条讲**多条业务线之间的利润结构搭配**(硬件薄利 + 服务厚利);本能力讲**单条业务线内部的定价与产品力**。问"要不要再开一条产品线"→ 第二曲线;问"这条产品线怎么定价、要不要投广告"→ 本能力。
- 与 `kan-guang-gao` 的区别:看广告是**从投放中的广告反推行业/岗位/项目**(找机会);本能力是**判断广告为什么有效/无效**(读竞争)。看到一条持续投放的广告,先用看广告法找方向,再用本框架判断它的护城河在供应链还是在投流。
- 与 `luo-ji-si-wei-lian` 的区别:逻辑链提供推理骨架;本能力是骨架在"定价"这一格上的**特化模型**,提供 `性/价/供应链` 三个具体变量。
- 与 `zui-xiao-shi-yan-ti` 的区别:最小实验体管风险;本能力管**胜率与定价权**。

## E — 可执行步骤 (Execution)

1. **拆解"性"。** 写下产品的**功能性**与**实用性**要点,并标明:哪些是消费者**购买前就能分辨**的(大众消费品),哪些**使用前无法分辨**(专业品)。这一步决定后面走"打价格"还是"打信任"。
2. **拆解"价"。** 写下:当前定价、毛利率、单笔利润额。
   - 计算时**必须分开看毛利率与单笔利润量级**(20万×10%=2万 ≠ 1000×30%=300)。
3. **估算消费者权重。** 判断目标人群更看性还是更看价。若不看价,进一步确认支撑溢价的是品牌还是信息不对称(如医美资质、专业品科普成本)。
4. **核算供应链结构(核心)。** 逐项问:原材料是否自有?生产是否自有(自建 / 代工)?渠道链路能否缩短?算出"自建 vs 代工"的成本差。
   - 得出结论:**我是否拥有最低定价权?** 拥有 → 可打性价比战并配投流围剿对手;不拥有 → 不可打价格战,只能走差异化/信任/合规壁垒。
5. **决策广告投入。** 用"广告团队赚的是产品力不行的钱"这条自检:
   - 若必须靠投流才能卖动 → 先回头改定价或改供应链,而不是加投放预算。
   - 若产品有定价权 → 可以把省下的成本差额(如那 60 块中的 20 块)用来买流量压制对手。
6. **压力测试竞争对手。** 列表:主要对手的成本结构、资金储备、是否可能降价。
   - 形成结论:若打价格战,我方资金能撑多久。
   - 完成后输出:"性/价拆解表 + 供应链成本差 + 定价权结论 + 广告投放建议 + 价格战承压测算"。

**停止条件**:定价权、广告策略、价格战承压三项结论均已给出;或用户问题实为"要不要开第二条产品线"(改走 `di-er-zeng-zhang-qu-xian`)。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **专业品 / 管控型行业**（医美、医疗、美白针等）：这些品类"使用前无法分辨、科普成本太高"，竞争壁垒是**资质合规**与**信任/安全意识**，不是性价比。对这些品类套用价格战会直接踩合规红线。
- **用户问的是"要不要开第二条产品线"**：属于 `di-er-zeng-zhang-qu-xian`。
- **涉及具体企业/个人的经营结论**：视频 009 的举例属主播单方观点，不构成对任何企业的经营结论。
- **纯投资/融资建议**：涉及资金储备与烧钱对抗的部分，不构成本能力可推荐的内容。

### 作者在书中警告的失败模式

- **靠投流掩盖定价过高**（ce27）：广告费是产品力缺陷的付费补偿，加投放只会更亏。
- **把毛利率当单笔利润**：忽略量级会导致定价决策完全错误。
- **供应链不归你却打价格战**：没有成本优势就谈"永远比你便宜"属于幻觉。
- **以为 IP/品牌能扛住极致低价**：在存量市场该假设被明确否定。

### 作者的盲点 / 时代局限

- **框架绑定"大众消费品 + 供应链自有"前提**：换到专业品/服务型业务时判据需整体重写。
- **对"信息强度"未给量化判据**：什么算"能在购买前分辨"，全靠使用者判断。
- **忽略渠道成本**：缩短链路有时会牺牲覆盖与便利，主播只算了成本差，没算规模代价。
- **存量市场假设**：若市场重回增量，"打信任/打品牌"可能重新优于"打价格"。

### 容易混淆的邻近方法论

- **波特五力**：讲行业结构；本能力讲单个产品的定价权来源。
- **定价心理学**：讲锚点与感知；本能力讲成本结构与消费者权重。
- **"薄利多销"**：只讲现象；本能力讲为什么能薄利——因为供应链差。
