# 鲁大魔 · 视频口播文案合集 — 术语表（作者本人的用法）

> 本文件回答「某个词在这套方法论里是什么意思」。**注意：以下定义是作者本人的用法，与通用含义常有差异**，差异列尤其重要。

| 术语 | 作者的定义 | 和常识用法的差异 |
|---|---|---|
| **生存技能** | 能换到钱的、可转化为物质价值的专业技能，本质是「使用工具的能力」 | ≠ 泛泛的「技能/爱好」。判断标准是能否换钱，不是能否考试 |
| **逻辑 / 逻辑思维** | 生活积累的「数据」形成「秩序」，秩序之间有因果关系构成逻辑，逻辑用于做决策。是人解决 90% 问题的「通用解决方案」 | ≠ 逻辑学 / 形式推理。是经验数据的因果网络，靠生活阅历喂养 |
| **数据 / Sense / 感知力** | 生活、工作两个维度中观察到的具体参数与感受（价格、体积、使用感受、人的行为习惯） | ≠ 统计学数据。是「生活感知力/工作感知力」意义上的经验颗粒 |
| **经济账 / 生存账** | 在做事过程中权衡利弊、算谁能交往谁不能交往的长周期生存计算 | ≠ 财务账。是生涯层面的成本收益判断 |
| **最小模型 / 最小实验体** | 把要验证的事缩到最小规模去做，实验体越小风险越小 | ≠ MVP 产品概念。主播强调的是「用最小代价换最大信息」 |
| **降低风险 ≠ 规避风险** | 风险不可规避，只能降低；降低的杠杆是控制实验体规模 | 常识常把「规避风险」当目标，主播认为这是不可能的幻想 |
| **抽象** | 贬义标签：该做具象的事却去聊人生、情感叙事、宏观方向 | ≠ 学术意义的「抽象思维」。是「不做具体事」的代名词 |
| **情感叙事** | 用「我老婆孩子父母怎么样」「我多辛苦多委屈」替代做具体事 | 常识中「叙事」是中性的；主播将其定义为失败者的语言习惯 |
| **宏大叙事** | 用「这个行业未来怎么样」「大环境怎么样」替代做具体事 | 同上，属被污名化的语言习惯 |
| **品牌隔离** | **重新做一个产品**，用全新资质做产品牌 | ≠ 子品牌。主播明确否定「子品牌」就是品牌隔离 |
| **第二增长曲线** | 第一产品线不赚钱也能做，但必须有第二个产品线承接利润与生态；依赖规模效应 | ≠ 泛泛的「多元经营」。强调必须有规模效应才能启动 |
| **性价比** | 性 = 产品的功能性 + 实用性；价 = 定价 + 利润策略；两者在消费者心中的权重占比决定竞争胜负 | ≠ 单纯的「便宜」。是可拆解为两轴并加权的分析工具 |
| **供应链系统** | 由供应链团队、供应链管理、供应链链路组成的完整管理体系，配件越复杂越需要系统 | ≠ 单纯的「进货渠道」。强调成熟度决定竞争身位 |
| **信息索引能力** | 主动搜索、主动积累信息的习惯，对应「数据层」的积累动作 | 主播自造概念。对立面是被动刷到（算法投喂） |
| **换不到钱的人** | 具备五种特征（情感叙事 / 宏大叙事 / 缺职业技能 / 缺信息索引能力 / 信命运）的人 | ≠ 贫困者的道德评判。主播将其定义为可观测的语言与行为习惯 |
| **当刺客** | 入职目标行业的公司打工，带着学习目的摸清流程 | 主播自造说法，带有对抗性暗示（打工是手段不是目的）。⚠️ **≠ 下方 v1.2 的「刺客式调研」**——两者来源不同、含义不同，不要混用 |
| **四个基本点** | 检验目标能否落地的四条：显性 / 具象化 / 可量化指标 / 可执行 | ≠ 管理学 SMART 原则。多出「显性」与「具象化」两个视觉维度 |
| **需求倒推** | 从需求向下逐层推演到可执行动作，而非从风口向上猜 | ≠ 用户调研。强调链条必须推到「加谁的联系方式」 |
| **翻船博弈理论** | 站在头部的人如何与追赶者竞争的分析框架 | 主播借用的博弈论术语，具体内容依上下文而定 |
| **换环境 / 变量论** | 人生结果 = 常量（发心）× 变量（环境/圈子/行业）；结果长期不变说明变量没变 | ≠ 鸡汤式「改变自己」。强调主动更换物理环境 |
| **过紧日子状态** | 消费信心不足、市场增量匮乏的存量竞争环境 | 主播对 2026 年市场环境的判断，为其「性价比优先于 IP」的结论提供前提 |
| **底层逻辑 / 本质逻辑** | 主播高频使用，泛指其归因框架（往往指供应链、需求、效率等） | 属于口头强调词，无严格定义，引用时需回到具体语境 |

### v1.1 增补术语（来自另一个鲁大魔技能包，非口播原文）

| 术语 | 来源包的定义 | 和常识用法的差异 |
|---|---|---|
| **避坑优先法** | 评估项目先看失败案例，强制拆解 3 个以上失败案例的致命点；"避开坑，剩下的就是利润" | ≠ 常规风险评估。强调**数量下限（3 个）与输出顺序（先坑后利）** |
| **致命点** | 失败案例中的**结构性**原因（流量与变现错配、现金流撑不住等），不是"他没坚持" | ≠ 失败原因。必须可映射回自己的方案并转成红线 |
| **泛流量 / 精准流量** | 泛流量＝人群杂、因内容而来的围观者；精准流量＝带着具体问题而来的人 | ≠ 流量多少。是**性质**判断，决定变现方式 |
| **流量错配** | 用泛流量做精准生意，或用精准流量接广告 | ≠ 转化率低。是结构性错配，靠加量只会放大亏损 |
| **李鬼矩阵** | 注册近似品牌抢占头部品牌流量的打法（来源包原始表述） | ⚠️ 本包**不作为可执行方案**，有商标侵权与不正当竞争风险；卡内只保留合法替代与防御动作 |
| **矩阵** | 同一主品牌下的多账号/多触点布局，统一沉淀到主阵地 | ≠ 李鬼矩阵。区别在于是否借用他人商誉 |
| **人才围剿** | 区域化创业时，把该区域内某职能的从业者列到**可数**再逐个建立关系并聚拢 | ≠ 常规招聘。是主动的、区域性的、以"可数"为前提的聚拢 |
| **海鸥模式** | 用培训/内容筛出精准用户，再把其中一部分转化为销售渠道 | ≠ 多层分销。本包限定为**单层、无入门费、返佣来自真实成交** |
| **最小切口** | 大项目撕个口子深挖一厘米；只干"离开大平台也能独立运行的高利润环节" | ≠ 最小实验体。切口是**选哪一环**（结构），实验体是**做多大**（规模） |
| **信息位 / 体力位** | 同一行业内，能看到定价、客户、渠道、结算的岗位叫信息位；纯执行岗叫体力位 | 主播自造说法（见打工起步法）。选岗时信息位优先，哪怕起薪低 30% |
| **处世三红线** | 亲人（隔离情绪）/ 朋友（隔离金钱）/ 合伙人（隔离模糊）三条边界规则 | ≠ 通用人情世故。每条都带具体止损动作与零容忍清单 |
| **8 年沉淀期** | 从搬砖到做公司所用的时间尺度，用于校准"多久能成"的预期 | ≠ 励志口号。是一个可参照的量化锚点（单一自述样本） |

### v1.2 补齐术语（2026-10-09 覆盖审计后补入）

| 术语 | 来源包的定义 | 和常识用法的差异 |
|---|---|---|
| **刺客式调研** | 以买家身份接触一个具体标的，逐层摸到成交价、成交逻辑与售后底线的调研方法：加联系方式 → 看朋友圈 → 套话术 → 摸价格 → 踩坑点 | ⚠️ ≠ 上表「当刺客」（入职打工摸流程）。且本包已把来源包的"**全程伪装客户**"收窄为"**保留购买意图**"——不虚构主体、不假签合同、不套取商业秘密 |
| **工具化沉淀** | 把能力做成可复制的载体（模板 → 清单/SOP → 脚本或工具 → 产品），使其脱离本人时间也能交付 | ≠ 泛泛的"做产品/做课"。本包加了三条判据：可复制性（3 次交付步骤重合度 ≥70%）、时机滞后（人肉成交 ≥10 次）、载体不跳级。**本包证据等级最低的一条，属"主张"而非验证过的规律** |

## 使用提示

1. 遇到术语时**不要代入常识含义**——本表右侧一列是理解偏差的关键。
2. 「抽象」「情感叙事」「宏大叙事」在本方法论中是**贬义标签**，用于负面诊断，不是中性描述词。
3. 「生存技能」「换不到钱的人」「当刺客」「信息索引能力」「四个基本点」若在通用语境中查不到对应含义，属正常——它们是主播在此基础上重定义或自造的概念。
