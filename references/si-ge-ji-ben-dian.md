# 四个基本点（显性 / 具象化 / 可量化指标 / 可执行）

## R — 原文 (Reading)

> 第一，显性，具象化。第二，可量化的指标、可执行的…显性是什么？显性就是你眼睛能够看到它…什么是具象化呢？就是通过我给你沟通的描述，你脑子里有一个具象化的场景和画面…第三个什么呢？就是指标，可量化的指标…第四个就是可执行的。

> 你要有一个具象化的项目，比如说，我今天我是卖奶茶的，我破圈，想搞资源搞什么？我去搞一搞，去实体圈，去看看谁是我奶茶原材料的生产厂商，上下游的。

— 鲁大魔，096 鲁大魔，四个基本点 努力把自己打磨得越来越酷就好～（2026-06-27，3分1秒）／137 努力不分年纪 敢拼才有奇迹（2026-06-10，4分20秒，同内容）／102 不要心比天高（2026-06-23，3分3秒）

## I — 方法论骨架 (Interpretation)

这是一个**目标验收器**，作用是判断一句话到底是"目标"还是"愿望"。四条必须同时满足：

1. **显性** — 眼睛能看到它。看不到的东西（"提升自己""变得更优秀"）不构成目标。
2. **具象化** — 脑子里有场景和画面。主播的用法是"通过我给你的描述，你脑子里有一个具象化的场景"——如果描述完你自己都想不出画面，就还不具体。
3. **可量化的指标** — 关键节点必须数字化。这个数字不必是钱（他在别处明确说过"这个指标绝对不是钱"），可以是单量、时薪、客户数、复购次数。
4. **可执行** — 以现在的能力短期够得着。判据是：能不能明天就动手。

与常见的 SMART 原则相比，这条方法论的重心有两个独特处：

- **"显性"** 要求目标在视觉上可见，这比 SMART 的"具体"更硬；
- **"具象化"** 要求脑内有画面，这直接对治主播最痛恨的"抽象"——他反复用"抽象"这个词批评那些聊人生、聊大方向的人。

反过来用，它也是一把**照妖镜**：任何一个口号式目标（"我要创业""我要做自媒体""我要提升认知"）代入四条，大概率四项全不满足。这时正确的动作不是"更努力"，而是把它改写成四要素齐备的句子。

## A1 — 书中的应用 (Past Application)

### 案例 1：把"破圈找资源"改成具象化项目（102）
- **问题**：粉丝想破圈认识人、拿资源，但说不清自己要做什么。
- **方法论的使用**：主播要求先有"具象化的项目"——"我今天我是卖奶茶的，我破圈，想搞资源搞什么？去看看谁是我奶茶原材料的生产厂商，上下游的"。项目一旦具象化，"找谁、去哪、谈什么"全部自动显形。
- **结论**：没有具象化项目，"破圈"就是空转。
- **结果**：把社交行为改造成有明确对象的商业行为，并明确"必须是带着项目去找资源，而不是带着资源找项目"。

### 案例 2：业务增长框架的拆分要求（015）
- **问题**：限制酸奶品牌老板说"没有事儿干"，想聊个人成长。
- **方法论的使用**：主播要求他先建立增长框架，且"每一个模块，它都需要你再进一步给它拆分…要把它拆碎了，揉碎了…你会发现，你可能需要很多人，要给它揉碎了，进一步的揉揉揉揉，搬碎了，你会更清晰了"。
- **结论**：拆分到能落到具体人和具体动作，才叫可执行。
- **结果**：把"我该如何提升"的抽象提问，换成"渠道/选址/招人/供应链/运营"五模块的拆分作业。

### 案例 3：四个"聪明人"要素的对照（078 / 096 相关）
- **问题**：如何识别一个人是否真能成事，以及如何自查。
- **方法论的使用**：在 096 里给出四基本点后，配套 078 给出行为特征（执行力、耐力深耕、专注、长期学习）作为"聪明"的重新定义——两者都是**把模糊评价换成可观测特征**的同一思路。
- **结论**：可观测性本身就是方法。
- **结果**：形成一套自查与他查的通用工具。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 定了一个年度/季度目标，但过了很久发现没有任何推进。
2. 准备写计划、做汇报、给团队派任务，需要判断"这个目标能不能落地"。
3. 总觉得自己"很忙但没结果"，想检查自己的目标表述是否有问题。
4. 有人给你一个听起来很正确的建议（"提升认知""打造个人品牌"），你想知道怎么把它变成动作。
5. 需要给下属/合伙人分配工作时，发现对方听不懂。

### 语言信号 (用户的话里出现这些就应激活)

- "我这个目标为什么总是落空？" / "Why do my goals never stick?"
- "怎么把这件事落地？" / "How do I actually execute this?"
- "我要提升自己 / 要做自媒体 / 要打造个人品牌"（典型的口号式目标）
- "我该怎么拆解这个计划？"
- "我说了他听不懂"

### 与相邻 skill 的区分

- 与 `luo-ji-si-wei-lian`（逻辑思维链）的区别：逻辑链诊断**判断依据的数据层**（我凭什么这么想）；四基本点验收**目标的表述形式**（这件事说不说得清）。用户问"我为什么判断错"→ 逻辑链；问"我为什么做不成"→ 四基本点。
- 与 `fan-mo-shi-zi-jian`（五特征自检）的区别：四基本点是**正向验收**（目标是否可落地）；五特征是**反向诊断**（人为什么不出结果）。一正一反，配对使用。
- 与 `zui-xiao-shi-yan-ti`（最小实验体）的区别：最小实验体管**规模**；四基本点管**表述**。一个目标通过四基本点验收后，接着用最小实验体定规模。
- 与 `di-er-zeng-zhang-qu-xian`（增长框架）的区别：增长框架是**内容清单**（该有哪些模块）；四基本点是**质量校验**（每个模块是否可落地）。

## E — 可执行步骤 (Execution)

1. **取出用户的目标原句，逐字抄录**
   - 做法：不要复述、不要美化，用原话。
   - 完成标准：拿到一句完整的原句。

2. **逐条代入四项检验，每条给"是/否"+ 证据**
   - ① **显性**：这件事眼睛能看到吗？证据是什么？（"提升自己"→ 否；"每周产出 1 条视频"→ 是）
   - ② **具象化**：说完之后脑子里的画面是什么？请用户描述画面。（说不出画面 → 否）
   - ③ **可量化指标**：关键节点有数字吗？（不给数字 → 否）
   - ④ **可执行**：以现在的能力，明天能动手吗？（需要先具备某个前提 → 否）
   - 完成标准：四项各有明确的"是/否"与一句理由。

3. **对不满足的项给出改写**
   - 做法：把抽象词替换成可观测内容。示范：
     - 原句："我今年要提升自己" → 改写："三个月内用 AI 接单做标书代写，做到第 10 单；每单客户在本地；客单价 ≥500 元；先做熟人 1 单。"
   - 完成标准：改写后的句子四项全满足。

4. **确认"指标不是钱"这条限制**
   - 做法：提醒用户指标可以是钱，也可以不是。若一件事现阶段该观测的是能力/流程（如 `zui-xiao-shi-yan-ti` 里"指标绝对不是钱"），允许量化指标落在复购次数、交付完成率、客户数上。
   - 完成标准：指标与"当前阶段要验证什么"匹配。

5. **输出"明天唯一动作"**
   - 做法：从改写后的句子里抽出明天就能做的第一步。
   - 完成标准：用户能复述一次，且该动作不依赖任何未具备的前提。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **探索阶段、方向尚未确定**：此时强行量化会过早锁死方向，应该先用 `kan-guang-gao` / `xu-qiu-dao-tui` 找方向。
- **创意/研究类工作**：这类工作的早期产出难以量化，硬套四条会压制探索。
- **用户已明确可执行且在推进**：不需要每次都做四检。反复验收会变成拖延。
- **纯情绪疏导场景**：用户需要的是被理解，不是被验收目标。

### 作者在书中警告的失败模式

- **用大梦想立 flag**（ce25）：宣言替代执行。
- **盲目总结成口号**（ce26）：把系统化方法压缩成一句口号。
- **把迷茫当终点**（ce24）：用"我迷茫"作为不行动的借口。
- **空谈项目 / 追热点概念**（ce27）：如无具象业务就想做 web3。
- **聊人生/宏观方向/个人成长**（ce02）：在最简单的事没做好时谈战略。

### 作者的盲点 / 时代局限

- **四条的"具象化"判定主观**：什么叫"脑内有画面"没有客观标准，容易变成 agent 的个人判断。
- **对长期目标不友好**："可执行"要求短期能力够得着，这会系统性低估需要 3–5 年积累的目标（如写一本书、做一个研究）。
- **量化指标的选取缺少判据**：主播说"指标不是钱"，但没给出"该选哪个指标"的方法，使用者容易选到与假设无关的 vanity metric。
- **与"梦藏于心"存在轻微张力**：他一边要求目标具象化，一边要求梦想藏起来不要公开立 flag。区别在于"对内具象化、对外不声张"，但这个区分需要使用者自己把握。

### 容易混淆的邻近方法论

- **SMART 原则**：与本能力高度重叠，但本能力的"显性"与"具象化"更强地约束了感官可见性，且明确排除用钱作为唯一指标。
- **OKR**：讲目标与关键结果的层级；本能力讲单个目标的质量门槛。
- **5W2H**：讲要素完备；本能力讲可落地性。
