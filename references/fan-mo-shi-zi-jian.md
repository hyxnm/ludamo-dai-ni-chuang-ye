# 换不到钱的人的五特征自检

## R — 原文 (Reading)

> 赚不到钱的人呢，他们身上有很多的共同性。穷逼，身上第一个共同性，感情叙事…第二，宏大叙事…第三个，缺乏职业技能…第四个，就是她没有这个信息，索引能力…第五个，与辅顾无自封，会把自己放在一个封闭的环境下。然后开始相信命运，相信天命。这就是一个穷逼身上五大特征，百分之百正确。

> 喜欢动不动聊人生，聊情感叙事的，聊感情叙事的，聊宏观叙事的人，这些人都是有大毛病的，抽象。

> 一个广告，他能连续投放个一年，投放半年…他能投放超过半年，就说明他这个行业可以。

— 鲁大魔，048 换不到钱的人身上的共性（2026-08-06，12分46秒）／015 业务增长计划落实及具体工作内容（2026-09-07，12分13秒）／012 这段很详细了听懂，做到会不一样（2026-09-10，10分26秒）

## I — 方法论骨架 (Interpretation)

这是全书最适合"立刻自用"的一条：把"为什么我赚不到钱"这个情绪化问题，转成一份**五条可观测的检查清单**。

**五个特征：**

1. **情感叙事** — 张口就是"我老婆怎么样、我孩子怎么样、我父母怎么样"，用诉苦和关系代替做事。主播的判据很狠：这种沟通"只能让别人获得一些同情，获得一些情绪下来"，而你现在需要的是钱，不是同情。
2. **宏大叙事** — 动辄谈行业未来、发展大方向、宏观经济。013 里他说得更白："你做的事情明明可以把它做得更好，有更好的方法…你现在不去想这个，能把你现在做的事情做得更好的方法，你去给我聊人生，聊他妈的宏观方向。"
3. **缺乏职业技能** — 在哪个行业，行业知识与能力深度都不够。
4. **缺乏信息索引能力** — 这是他自造的概念，指**主动去找行业信息的能力**。判据非常具体："哪怕你是每天看一个广告，说一个广告分析，她都可以"——连这个都不做，就是没有索引能力。
5. **固步自封 + 信命运** — 把自己放在封闭环境里，然后开始"相信命运、相信天命"。

**为什么这份清单值得做成能力，而不是鸡汤？** 因为第 1、2 条把"语言习惯"识别成了致贫特征。这不是道德批判，是行为观察：你在日常里说什么话，直接决定你的注意力投向哪里。成天说情感叙事的，注意力在关系里；成天说宏大叙事的，注意力在评论里；两者都不产生可换钱的具体动作。

第 4 条则是这份清单里唯一**自带解法**的：没有信息索引能力，就去主动搜索、每天看一个广告做分析、连看 90 天到 180 天，"你就自然知道谁赚钱，谁不赚钱"。

## A1 — 书中的应用 (Past Application)

### 案例 1：农村出身、赚到一千万的粉丝连麦（048）
- **问题**：一位从农村出来、赚到过一千万的粉丝，钱守住了（还有一千万现金），但"人变了"，问怎么修行自己。
- **方法论的使用**：主播把他的表现逐条对号——他反复讲自己怎么翻身、买大 G、买表，"都是为了证明自己"，属于情感叙事；同时又聊行业、聊大势，属于宏大叙事。主播当场判定"这几句话你都说的真的很到尾"，五特征他全占。
- **结论**：赚到过钱不等于是非特征已消除——有些特征会在有钱之后以新的形式回来（从诉苦变成炫耀）。
- **结果**：主播给了两条非常具体的动作：第一，不要跟别人感情叙事；第二，不要宏大叙事。"提这个事情不可能让你赚来任何人（的钱），只能让别人获得一些同情。"

### 案例 2：旅游淡季粉丝的提问（012）
- **问题**：一位做旅游的粉丝，反复问"我觉得这个行业怎么样"，但答不出自己要卖什么、卖给谁。
- **方法论的使用**：主播指出他"老是聊同行，聊大方向，聊同行，聊别人"，而"只要谈论到自己的缺失部分，就得转移话题"。这是宏大叙事的典型——用评论行业来回避自己的具体缺口。
- **结论**：转移话题是宏大叙事的核心机制。
- **结果**：被要求"专注到自己"，并当场被给了完整的可执行方案（从需求向下推演，见 `xu-qiu-dao-tui`）。

### 案例 3：每天看一个广告连看 180 天（048）
- **问题**：年轻人说不知道学什么、不知道哪个行业赚钱。
- **方法论的使用**：补第 4 条（信息索引能力）的解法——"你每天看一个广告，每天看一个广告，你连看 180 天，连看 90 天，你就自然知道谁赚钱，谁不赚钱了"。判据是：能连续投放半年的广告主不傻，"如果他投一个月不赚钱…他就直接不投放"。
- **结论**：索引能力是可以靠固定动作训练出来的，不需要天赋。
- **结果**：这条动作与 `kan-guang-gao` 完全同源，形成"诊断（本能力）+ 处方（看广告）"的闭环。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 长期很忙、很累，但收入与能力两年没变化，想找出根因。
2. 反复在同一个坑里失败（项目做不成、工作不顺），怀疑是环境问题。
3. 准备请人给自己做职业/创业诊断，想先自查。
4. 要评估一个潜在的合伙人/团队成员是否值得合作。
5. 刚赚到一笔钱或刚翻身，担心自己"飘了"，想保持清醒。

### 语言信号 (用户的话里出现这些就应激活)

- "为什么我很努力但赚不到钱？" / "I work hard but I'm not making money"
- "我是不是有什么问题？" / "What's wrong with me?"
- "这两年我一点没长进"
- "我觉得这个行业不行了/未来趋势是……"（宏大叙事的强信号）
- "我老婆/我家里/我爸妈……"（情感叙事的强信号）
- 描述里大量出现"我觉得""我感觉""我朋友说"而缺少具体数字

### 与相邻 skill 的区分

- 与 `luo-ji-si-wei-lian`（逻辑思维链）的区别：逻辑链诊断**数据层够不够**（我凭什么这么判断）；五特征诊断**语言与行为习惯**（我每天在说什么、做什么）。用户问"我的判断为什么不靠谱"→ 逻辑链；问"我为什么没结果"→ 五特征。
- 与 `chuang-ye-liu-bu`（创业六步）的区别：六步是**业务层面的顺序检查**；五特征是**个人层面的习惯检查**。可以并行使用，但一个是查事，一个是查人。
- 与 `kan-guang-gao`（看广告倒推）的区别：看广告是**第 4 条的处方**；本能力是**诊断清单**。诊断出第 4 条命中 → 直接转 `kan-guang-gao`。
- 与 `si-ge-ji-ben-dian`（四个基本点）的区别：四个基本点是**正向验收**（目标是否可落地）；本能力是**反向诊断**（人为什么不出结果）。

## E — 可执行步骤 (Execution)

1. **先取得真实的语言样本，而不是让用户自我评价**
   - 做法：请用户用 3 分钟描述自己最近一个月的状态和困扰；同时请他复述最近最常说的三句话。不要问"你有没有情感叙事"，问"你最近一次抱怨是什么内容"。
   - 完成标准：拿到可判断的具体语料（≥3 句），而不是"我挺好的"。

2. **逐条对照五个特征，并标记证据**
   - ① 情感叙事：出现频率？谈自己 / 谈家人 / 谈委屈的内容占多少？
   - ② 宏大叙事：有没有在评论行业趋势、宏观方向、别人的对错，而答不出"我明天做什么"？
   - ③ 职业技能：有没有一项**已被换钱验证过**的技能（承 `sheng-cun-ji-neng` 的标准）？
   - ④ 信息索引能力：最近 30 天主动搜索过几次行业信息？有没有做过一次广告分析？
   - ⑤ 固步自封 + 信命运：是否把结果归因于运气、出身、贵人、天命？
   - 完成标准：五条各给出 命中 / 未命中 + 一句证据。

3. **按命中数给出结论（不要模糊化）**
   - 做法：命中 ≥2 条即判定"问题不在努力程度，在注意力投向"；命中 0–1 条则本清单不适用，转向其他诊断（如 `luo-ji-si-wei-lian` 的数据层检查）。
   - 完成标准：给出明确判定，不用"有点""可能"。

4. **针对命中项给一条可执行处方**
   - 做法：
     - 命中 ①② → 处方是**语言禁令**：接下来两周内，停止向任何人讲述自己的委屈与行业评论；被问到就说具体动作与数字。
     - 命中 ③ → 转 `sheng-cun-ji-neng`，先做技能清算 + 第一步变现测试。
     - 命中 ④ → 转 `kan-guang-gao`，做"连续 7 天每天一条广告分析"的训练。
     - 命中 ⑤ → 处方是**换环境 + 记录自己可控的动作清单**，把归因从外部拉回可操作项。
   - 完成标准：处方必须是**两周内可完成**的单一动作，不是"提升认知"。

5. **设定复检时点**
   - 做法：两周后复看同样五条，重点看①的语料是否变化。
   - 完成标准：能对比出语言样本的差异，而不是靠感觉。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户处于真实的结构性困境**（重病、意外、行业整体崩塌、被裁员）：此时把问题归因于"你的语言习惯"是残酷且错误的。
- **用户问的是具体业务问题**（定价、选址、投流）：那属于 `xing-jia-bi-yu-gong-ying-lian` / `di-er-zeng-zhang-qu-xian` 的范围。
- **用户只是情绪低落、需要倾诉**：这是本清单的高危场景。主播自己也在用"情感叙事"标签打击人，但一个助理在用户难过时使用这份清单，会把支持变成羞辱。**先处理情绪，不要在这时启动诊断。**
- **用户已经命中 4–5 条且状态很差**：不要一次抛出全部，会造成压垮。逐条给、每次一条。

### 作者在书中警告的失败模式

- **相信命运 / 把结果归因于外部**（P036、ce24）：把自己放在封闭环境里，然后开始相信天命。
- **把迷茫当终点**（ce24）：用"我迷茫"作为不行动的合法借口。
- **盲目总结成口号**（ce26）：把系统化方法压缩成一句"慢慢来"，等于没听。
- **用低门槛兼职替代技能积累**（ce22）：把送外卖/跑腿当作长期出路。
- **把"研究人脉/进圈层"当破圈方法**（ce28）：无项目就想找资源。

### 作者的盲点 / 时代局限

- **归因过于个人化，忽略结构性因素**：主播把"换不到钱"整体归到个人习惯上，几乎不承认行业周期、地域差异、家庭负担的影响。这会造成对受害者的二次伤害。
- **"情感叙事"的判定过于宽泛**：正常的家庭沟通、必要的情感表达也可能被划入。清单缺少"多少算过量"的阈值。
- **"宏大叙事"存在自相矛盾**：主播自己大量谈论行业、商业结构、宏观判断（008、009、075 全是宏观分析）——他反对的是**只谈宏观不做事**，而不是宏观思考本身。使用者必须自己补上这个限定。
- **表达方式带有攻击性**：原话大量使用侮辱性词汇。作为能力卡使用时必须剥离语气，只保留可观测的行为判据。

### 容易混淆的邻近方法论

- **"穷人思维/富人思维"类畅销书**：泛化、无判据。本清单的优势在于五条都**可观测、可复检**（尤其第 1、2、4 条）。
- **课题分离（阿德勒）**：讲不必背负他人评价；本能力讲不要把注意力投向叙事。
- **成长型思维**：讲对失败的信念；本能力讲对失败的语言与行为反应。
