# 求职避坑与面试实战（查资质 / 改简历 / 说实话）

## R — 原文 (Reading)

> 查资质：天眼查、企查查必查。看经营异常、法律诉讼、营业执照范围。
> 问细节：明确底薪+提成+绩效构成，明确发薪日，明确社保缴纳。含糊其辞的直接 Pass。
> 识陷阱：警惕"零门槛、高薪资、包吃住"的离谱广告。
>
> 不造假，要放大："会 Excel" → "熟练使用 Excel 统计排版，曾独立完成 500 份以上数据整理"；"发过传单" → "3 天完成 500 份发放，锻炼了基础抗压与沟通能力"。
>
> 面试"实话说"：不背模板，说直白话。遇到不会的直接说"目前不了解，但愿意学"，比瞎编乱造更有说服力。内向者承认内向但强调细心、有耐心。

— 《鲁大魔·全能逆袭智库》logic/sub_skills/job_hunting.md、B 包 templates/job_audit.md（本包对应文件：templates/job-audit.md）

## I — 方法论骨架 (Interpretation)

A 包的 `da-gong-qi-bu`（打工起步法）解决的是"**为了学东西，我该去哪个岗位**"；本卡解决的是前半程另一个问题："**这家公司是不是坑、我怎么拿到 offer**"。两者是同一段路程的两截：选赛道 → **避坑 + 入职**（本卡）→ 摸流程。

这套方法由三块拼成，逻辑是**先排除，再放大，最后如实说**：

1. **排除（查资质）**：入职前用公开数据做一次穿透——经营异常、法律诉讼、营业执照范围。判据不是"公司大小"，而是"有没有它自己没说的风险"。
2. **放大（改简历）**：简历问题不是写得少，是写得**抽象**。"会 Excel"是抽象，"独立完成 500 份数据整理"是可验证。原则是**不造假、要放大**——把真实经历量化、具体化，而不是编造经历。配套一条反直觉的规则：**单页且只突出适配性**，行政岗就写细心，不写别的。
3. **如实说（面试）**：不背模板。内向者不装外向，承认内向 + 强调细心耐心；不会的题直接说"目前不了解，但愿意学"。理由是瞎编会在追问中崩塌，而"愿意学"在真实岗位上是可以兑现的。

**为什么这套值得单独成卡**：因为"求职"在 A 包里只是打工起步法的一个前置动作，而来源包把它做成了有查证工具、有改写范例、有评级标准的完整作业。特别是"问薪酬构成"这一步——它把 Offer 从"一个数"拆成"底薪 + 提成 + 绩效 + 发薪日 + 社保基数"五个可问项，任何一项含糊就是信号。

## A1 — 书中的应用 (Past Application)

### 案例 1：简历"放大"的两组改写（job_hunting.md §3）
- **问题**：普通经历（会 Excel、发过传单）在简历上没有竞争力，写上去也没人看。
- **方法论的使用**：不做假，只做量化与场景化——"会 Excel"改写成"熟练使用 Excel 统计排版，曾独立完成 500 份以上数据整理"；"发过传单"改写成"3 天完成 500 份发放，锻炼了基础抗压与沟通能力"。
- **结论**：竞争力差距不在经历本身，在**描述的可验证程度**。
- **结果**：给出可直接套用的改写公式：动词 + 数量 + 场景 + 结果。

### 案例 2：三级评级作为决策出口（B 包 templates/job_audit.md）
- **问题**：拿到几个 offer / 面试邀请，不知道该选哪个、该不该去。
- **方法论的使用**：把每个机会按四项核心指标（薪资透明度、社保基数、加班逻辑、离职率与舆论）审计后归入三档——稳健（符合底座，可尝试）／中风险（有模糊项，面试需追问）／巨坑（皮包公司/杀猪盘/重资产套路，坚决不去）。
- **结论**：选择不是比较优劣，是**先排除巨坑**。
- **结果**：把"选哪个更好"改造成"哪个先被否决"。

> **诚实标注**：来源包未给出带姓名与结果的真实求职案例，A1 的两条是作者给出的**改写范例与评级工具**本身（相当于方法的使用示范），证据强度记为「规则级」。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 手上有 offer 或面试邀请，拿不准这家公司靠不靠谱。
2. 投了很多简历没回音，怀疑简历写得有问题。
3. 面试总被刷，或一到面试就紧张、不知道该怎么说。
4. 看到"零门槛、高薪资、包吃住"这类招聘，心动但不确定。
5. 想转行，但没有目标行业的经验，不知道简历怎么靠过去。

### 语言信号 (用户的话里出现这些就应激活)

- "这家公司靠谱吗？" / "Is this company legit?"
- "简历怎么写 / 帮我改简历" / "help me with my resume"
- "面试该怎么说？我有点内向" / "how do I answer in an interview"
- "投了几十份没回复"
- "这个offer 底薪很低但提成高，要不要去？"
- "招聘写着零门槛高薪包吃住"

### 与相邻 skill 的区分

- 与 `da-gong-qi-bu`（打工起步法）的区别：打工起步法回答"**去哪个岗位能学到东西**"（信息位 vs 体力位、列观察清单）；本卡回答"**这家公司能不能去、我怎么进去**"。用户问"我想做宠物殡葬该去哪打工"→ 打工起步法；问"这家宠物医院靠谱吗/简历怎么写"→ 本卡。
- 与 `sheng-cun-ji-neng`（生存技能优先）的区别：生存技能判定"什么算能换钱的技能"；本卡处理技能已明确之后的求职动作。
- 与 `ci-zhi-jue-ce-yu-zhi`（辞职阈值）的区别：辞职阈值管**什么时候离开现在的岗位**；本卡管**怎么进入下一个岗位**。
- 与 `kan-guang-gao`（看广告倒推）的区别：看广告解决"进哪个行业"；本卡解决"进入的具体动作"。

## E — 可执行步骤 (Execution)

1. **穿透公司资质（查）**
   - 做法：用天眼查/企查查等公开工具查四项——注册资本与实缴资本、经营异常与法律诉讼、营业执照范围、成立时间。
   - 完成标准：四项都有明确记录；成立时间不足两年且无其他背书时标为"待观察"。
   - 判停条件：**出现经营异常、多起劳动争议诉讼、执照范围与招聘岗位明显不符** → 直接进入第 6 步的"巨坑"档。

2. **拷问薪酬结构（问）**
   - 做法：把 offer 拆成五个可问项——底薪、提成/绩效的计算方式、发薪日、社保缴纳基数与起始月、加班是否有加班费或调休。要求对方给数字。
   - 完成标准：五项都拿到明确回答。
   - 判停条件：**任一项含糊其辞或"转正后就好了"** → 记为中风险，需要追问；两项以上含糊 → 视为巨坑的信号。

3. **识别陷阱广告（识）**
   - 做法：对"零门槛 + 高薪资 + 包吃住"的组合直接打问号；交叉验证招聘平台上的员工评价、离职率讨论。
   - 完成标准：能说出至少一个独立信源的评价。
   - 判停条件：若岗位要求先交钱（培训费、押金、设备费）→ **立即终止，这是硬门**。

4. **改写简历（放大不造假）**
   - 做法：对每一条经历套用"动词 + 数量 + 场景 + 结果"；删掉与目标岗位无关的内容；单页控制。
   - 完成标准：每条经历都含一个可验证的数字，且与岗位要求一一对应。
   - 判停条件：**任何一条需要虚构** → 改写为可兑现的承诺（"目前不了解，但愿意学"），不写没做过的事。

5. **面试用"实话说"策略**
   - 做法：不背模板；内向者明确承认内向并补上"细心、有耐心"等可验证特质；不会的题直接说"目前不了解，但愿意学"；结束前主动问清"结果反馈周期"。
   - 完成标准：准备 3 个真实短板的可兑现说法 + 1 个必问的反馈周期问题。
   - 判停条件：若面试官要求现场编造经历或数据 → 这不是适配问题，是价值观冲突。

6. **出具三级评级**
   - 做法：按四项核心指标（薪资透明度、社保基数、加班逻辑、舆论）把每个机会归入**稳健 / 中风险 / 巨坑**三档。
   - 完成标准：每个机会都有明确档位；巨坑档直接排除，不做比较。
   - 判停条件：若所有机会都是巨坑档 → 结论是"继续找"，不是"挑一个相对不差的"。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户要的是高端职位/猎头场景**：本卡面向普通岗位与二本及以下求职者，高管谈薪与期权谈判不在范围。
- **需要具体法律判断**（竞业协议、劳动仲裁、试用期违法解除）：转介法律专业人士。
- **用户已有明确目标公司且只问业务问题**：直接用 `da-gong-qi-bu` 的观察清单。
- **境外求职**：天眼查/企查查只覆盖中国大陆工商数据，方法与信源都不适用。

### 作者（来源包）自身的盲点

- **"含糊即 Pass"过于绝对**：小公司与初创团队的薪酬结构常在早期不够规范，但未必是坑。应结合公司阶段判断，而不是一票否决。
- **"不造假要放大"的边界模糊**：量化的前提是你真的做过。把"参与过"写成"独立完成"就是造假——本卡要求数字必须可验证，这是硬要求。
- **查资质依赖第三方数据完整性**：企查查/天眼查的数据有延迟，诉讼与异常可能滞后或缺失，不能当作唯一依据。
- **未讨论"海投无效"之外的投递策略**：只批评盲目海投，没给出投递渠道与覆盖量的具体配方。
- **"实话说"并非在所有面试文化中都成立**：部分结构化面试要求行为事例（STAR），纯"愿学"表达会被判为缺乏证据。

### 容易混淆的邻近方法论

- **STAR 面试法**：结构化行为事例；本卡偏向如实表达，二者可叠加（用 STAR 讲真实经历）。
- **背景调查（背调）**：雇主对雇员做；本卡是雇员对雇主做，方向相反。
- **职业测评/职业规划**：解决长期方向；本卡解决一次性入职决策。
