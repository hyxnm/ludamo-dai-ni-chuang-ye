# 区域聚焦与最小切口（避开一线，撕开一厘米）

## R — 原文 (Reading)

> 区域聚焦与降维：避开一线卷王，深耕三四线或特定垂直领域。优势：掌握定价权，资源整合。
>
> 最小切口分析：大项目撕个口子，深挖一厘米。动作：打碎产业链，只干离开大平台也能独立运行的高利润环节。

— 《鲁大魔·全能逆袭智库》logic/methodology.md「商业项目拆解 10 大心法」第 7、8 条

> **来源说明**：出自技能包 B 的归纳文本，非 A 包原有 141 条口播切片转写。

## I — 方法论骨架 (Interpretation)

这是两条同源的法则，共同回答一个问题：**在哪个战场、切多深**。合并成一张卡是因为它们解决的是同一个决策的两个维度。

### 维度一：区域聚焦（在哪里打）

- **主张**：避开一线城市的"卷王"，去三四线或特定垂直领域深耕。
- **理由**：一线城市的竞争是**资本密度与人才密度的竞争**，草根在这两个维度上都输；三四线的竞争维度是**本地资源整合与执行密度**，这恰恰是草根能赢的。
- **收益**：掌握定价权（竞争者少）、资源整合成本低（本地关系可积累）。

### 维度二：最小切口（切多深）

- **主张**：把大项目撕开一个口子，深挖一厘米，而不是横向铺开。
- **筛选标准很关键**：只干**离开大平台也能独立运行的高利润环节**。这句话有两个筛选条件——①**可独立运行**（不依赖平台/大厂的流量或资质）；②**高利润**（不是走量环节）。
- **与 A 包 `zui-xiao-shi-yan-ti` 的关系**：A 包原话是"只做整个生态链里最简单的那一环"（规模维度：做最小）；本卡加的是筛选标准（结构维度：**可独立运行 + 高利润**）。两者合一才是完整判据：先按本卡选出**哪一环**，再按最小实验体决定**做多大**。

### 两个维度的组合

区域聚焦决定"**在哪个人群/地理范围内**"，最小切口决定"**在这个范围内做产业链的哪个环节**"。典型组合：在某个三四线城市，只做某个产业链里能独立跑通且高利润的一个环节。

## A1 — 书中的应用 (Past Application)

### 案例 1：灵匠科技选择徐州（biography.md）
- **问题**：2015 年创业，选在哪里、做什么。
- **方法论的使用**：选择徐州（非一线），早期做"卖系统"，后转型 ToB 大数据风控；先做区域内技术能力的聚拢（见 `ren-cai-you-xian`），形成淮海地区最大技术团队。
- **结论**：在区域市场里，规模不需要全国级就能成为本地第一。
- **结果**：10 人 → 150 人，区域技术垄断（来源包自述，未核验）。

### 案例 2：校园墙项目的 3 分钟回复（biography.md 商业哲学关键数）
- **问题**：校园墙这类小切口项目如何建立优势。
- **方法论的使用**：把切口压到极小（一个学校的校园墙），把服务标准压到极致——**3 分钟回复**。
- **结论**：切口够小，才可能做到大玩家做不到的服务密度；这个密度就是壁垒。
- **结果**："3 分钟回复"被来源包记为核心执行标准之一。

### 案例 3：域名撮合（biography.md）
- **问题**：2014 年出狱重启，没有资金，做什么。
- **方法论的使用**：选了一个**离开平台也能独立运行、且利润高**的极小环节——拿到域名持有人底价，转手卖给需要的企业，赚佣金。不囤货、不压资金（虚拟资产）。
- **结论**：撮合是最小切口的典型形态：只做信息差这一环，不做交付、不做库存。
- **结果**：3 个月赚取近百万元启动资金（来源包自述，未核验）。

> **诚实标注**：以上均为来源包自述事实，无第三方核验。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 想创业但身处一线，感觉竞争不过、成本太高，纠结要不要回老家/去下沉市场。
2. 看到一个"很大的"赛道（如新能源、AI、跨境），不知道从哪里切进去。
3. 想做某个产业链，但资金与团队都不够做全链路。
4. 在小城市做生意，不知道本地市场的机会在哪。
5. 已经在做一个环节，纠结要不要向上下游延伸。

### 语言信号 (用户的话里出现这些就应激活)

- "我在一线城市做不过别人" / "要不要回老家发展？"
- "这个赛道很大，我从哪切入？"
- "我想做整个产业链，但钱不够"
- "小城市有什么机会？"
- "要不要往上游/下游延伸？"

### 与相邻 skill 的区分

- 与 `zui-xiao-shi-yan-ti`（最小实验体）的区别：最小实验体管"**做多小**"（规模）；本卡管"**切哪一环、在哪个区域**"（位置与结构）。顺序：本卡先选环，最小实验体再定规模。
- 与 `kan-guang-gao`（看广告倒推）的区别：看广告选**行业**；本卡在行业内选**区域 + 环节**。
- 与 `ren-cai-you-xian`（人才优先）的区别：人才优先解决"靠什么打赢"；本卡解决"在哪里打"。二者配对使用。
- 与 `di-er-zeng-zhang-qu-xian`（第二增长曲线）的区别：第二曲线是**加第二条线**；本卡强调**先把第一条线切窄**。没切窄就谈第二曲线是叠加复杂度。

## E — 可执行步骤 (Execution)

1. **先判定是否该换区域**
   - 做法：比较三个维度——竞争密度（同赛道本地玩家数量）、成本结构（租金/人力/获客）、资源可得性（本地关系与人才）。
   - 完成标准：能说出目标区域在三项上的具体值，且与一线对比有明确优势。
   - 判停条件：若所选业务**必须依赖一线资源**（资本、特定人才、特定平台）→ 不下沉，回到原方案。

2. **打碎产业链，列出全部环节**
   - 做法：把目标行业拆成 5–10 个环节（原料/设计/生产/仓储/渠道/获客/交付/售后/培训…），逐个列出。
   - 完成标准：产出一张环节清单。

3. **用两个筛子选环节**
   - 做法：对每个环节问两句——①**离开大平台我能不能独立运行？**（不依赖平台的流量分配、资质或补贴）②**这个环节的利润率高不高？**（不是走量环节）。两个都是"是"才留下。
   - 完成标准：清单收敛到 1–3 个候选环节。
   - 判停条件：**一个都不满足** → 说明这个行业不适合单人/小团队切入，换行业（回 `kan-guang-gao`）。

4. **把切口压到"一厘米"**
   - 做法：对候选环节继续收窄——只服务一类人群、只做一个 SKU、只覆盖一个区域/一个渠道。
   - 完成标准：能用一句话说清"我只做 ___ 的 ___"。
   - 判停条件：若收窄后市场过小无法养活自己 → 回到第 3 步换一个环节，而不是放宽切口。

5. **验证可独立运行**
   - 做法：按 `zui-xiao-shi-yan-ti` 设计一个最小实验——在不接入大平台的前提下完成一次真实成交。
   - 完成标准：拿到一笔**不依赖平台分配**的收入。
   - 判停条件：若成交必须靠平台给流量 → 该环节不满足"可独立运行"，回到第 3 步。

6. **设延伸门槛**
   - 做法：为"要不要向上下游延伸"预设一个数字门槛（如单环节月利润稳定超过 X，或客户数超过 Y）。
   - 完成标准：门槛写清。
   - 判停条件：**未达门槛不延伸**——延伸是第二曲线的事，不是切窄阶段的事。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **需要规模效应才成立的生意**（平台、供应链、硬件）：切口过小会产出噪音而非信号，见 `zui-xiao-shi-yan-ti` 的同类警告。
- **强监管行业**（医疗、金融、教育资质）：能否独立运行取决于资质而非环节选择，先解决资质。
- **用户已在某个环节站稳、问题是增长**：那是 `di-er-zeng-zhang-qu-xian` 的范围，反复切窄会变成永远不放大。
- **纯线上、无地理属性的业务**：区域聚焦维度不适用，只用最小切口维度。

### 作者（来源包）自身的盲点

- **"三四线"是 2015 年前后的判断**：随着远程办公与全国性平台渗透，区域壁垒正在变弱，这条法则的时效性需注意。
- **下沉不等于低竞争**：下沉市场的本地关系壁垒高，外来者如果没有本地资源，反而比一线更难。
- **"高利润环节"往往已被占据**：能独立运行且高利润的环节，通常已经有人在做，来源包没有讨论"被占据时怎么办"。
- **忽略下沉市场的天花板**：区域市场容量有限，切窄之后可能长期做不大，这是取舍而非缺陷，但用户需要预先知道。
- **自述数据未核验**：10→150 人、3 个月百万、3 分钟回复均为主播自述。

### 容易混淆的邻近方法论

- **利基市场（Niche Market）**：强调细分人群；本卡强调**产业链环节 + 区域**两个维度。
- **蓝海战略**：强调开创无竞争市场；本卡是在既有产业链里挑一个可独立运行的高利润环节。
- **下沉市场策略**：通常指大公司的渠道下沉；本卡是草根的主动避战选择。
