# 辞职/转型决策阈值

## R — 原文 (Reading)

> 你就做这一件事情,给你那么多账号,让你开号重新去获客,用更多的账号来用矩阵化的打法去获客,然后用AI去写标书、简历优化,像这种做PPT。你试一下,如果你能在这个领域里面一个月能做到一万块钱,你就可以辞职了。
>
> —— 视频 105《辞掉编制,要去创业?先尝试完成这件事,再去考虑辞职!》(1分40秒)

> 选一个上限高的,短期之内,让自己的收入下降了30%,是没有问题的……只要这个新的工作,它的上限高,就完全可以尝试。
>
> —— 视频 030《选择上限更高的》(2分8秒)

---

## I — 方法论骨架 (Interpretation)

不要把「辞不辞职」「转不转型」当成一个态度问题或勇气问题,它是一个**阈值问题**。核心是两层判断:

1. **第一层:现金流验证阈值。** 在辞职之前,先用**业余时间 + 现有资源**把目标方向跑出一个可复现的月收入。主播给出的具体数字是**月入一万**。达到即视为"这个方向能自己养活你",未达到则不动。这让辞职从"赌一把"变成"达标后领奖"。

2. **第二层:上限换降薪阈值。** 如果暂时跑不到上面那条线,退一步看:是否值得用一个**降薪 30%** 的代价,去换一个**上限更高、有积累性**的岗位。判断依据不是当前工资,而是**这个岗位能不能积累出可迁移的专业能力**。行政、人事、打螺丝这类岗位收入天花板在 5000–10000 之间且无能力积累;主播、技术等岗位起薪可能只有六七千,但有专业知识积累,上限高。

两层判断的关系:**跑得出月入一万 → 直接辞;跑不出但目标岗位上限高 → 可以降薪 30% 先转岗再积累;两条都不满足 → 留在原地,继续用业余时间做实验。**

## A1 — 书中的应用 (Past Application)

### 案例 1：公务员/事业单位听众想辞职去直播（视频 105）
- **问题**：提问者已在体制内,反复表示"早晚也会被干掉,想辞职回去干直播"。
- **方法论的使用**：主播不评判对错,直接给出可执行路径——把家人的手机号全注册一遍小红书/快手/视频号/闲鱼/淘宝账号,做矩阵号获客,用 AI 接标书代写 / 简历优化 / PPT 制作三方向订单,并给出**月入一万才辞职**的硬阈值。
- **结论**：辞职前必须有一个可复现的收入数字作为判据。
- **结果**：提问者仍在纠缠"要不要辞",被主播打断:"我都告诉你第一步干什么、第二步干什么、第三步干什么了,你还在那哔哔。"

### 案例 2：行政主业 + 自媒体带货副业的 27 岁听众（视频 030）
- **问题**：主业月入 1 万但无技能积累,副业自媒体收入不稳定,纠结该深耕哪个。
- **方法论的使用**：主播先问年龄(27),给出的判断是"行政什么时候不能做?你 29 也能做""花一年时间直接去学直播带货",并明确"选一个上限高的,短期之内让收入下降 30% 是没问题的"。
- **结论**：起薪不是判据,上限与积累性才是。
- **结果**：给出"降薪 30% 换上限"的第二层阈值。

### 案例 3：跨境电商打工者发现公司快倒闭（视频 104）
- **问题**：听众已经进了一家看起来要倒闭的跨境电商公司,想换行业。
- **方法论的使用**：这条不是阈值问题而是**选公司的判据**问题,主播补充了打工前置条件(见能力 `da-gong-qi-bu`),本能力的第二层阈值在这里体现为:选择标准应当是"公司**成立两年以上**且**员工数 ≥ 20 人**"(能养 20 人说明发得出工资),而不是随便一家。
- **结论**：选公司与选上限是一回事——都看"能不能养活人、能不能积累"。
- **结果**：把"要不要换"转成"按什么标准换"。

## A2 — 触发场景 (Future Trigger) ★

### 用户会在什么情境下需要这个 skill？

1. 想辞职但拿不准——"我该不该辞职创业/全职做副业"。
2. 稳定 vs 高上限二选一——"现在收入稳定但没成长,要不要换个更累但更有前途的"。
3. 要不要降薪转行——"转行要降薪三成,值不值"。
4. 副业能否养活的判断——"副业做到什么程度才能全职"。
5. 体制内去留——"编制内想出来做自媒体,怎么判断时机"。

### 语言信号 (用户的话里出现这些就应激活)

- "我该不该辞职创业/全职做副业" / "Should I quit my job to go full-time?"
- "转行要降薪三成,值不值"
- "副业做到什么程度才能全职" / "How much income before going full-time?"
- "编制内想出来做自媒体,怎么判断时机"
- "这个工作很稳定，但我看不到天花板"

### 与相邻 skill 的区分

- 与 `zui-xiao-shi-yan-ti` 的区别:最小实验体解决"**用什么做实验**"——先把实验体做小、把不可逆损失挡在门外;本能力解决"**实验结果达到什么数字才允许做不可逆动作**"。两者是配套关系:**先有最小实验体 → 再跑阈值 → 才允许辞职**,顺序不能颠倒。
- 与 `da-gong-qi-bu` 的区别:打工起步法讲"**进门后怎么走六步**";本能力只回答"**门该不该出**"。
- 与 `luo-ji-si-wei-lian` 的区别:逻辑思维链是"数据→秩序→逻辑→决策"的通用推理骨架;本能力是把这套骨架**特化到辞职这一个决策**上,提供具体的数字阈值(月一万 / 降薪30%)和判据(上限、积累性)。遇到"要不要辞职"这类问题时应路由到本能力,而不是停在通用逻辑链上。

## E — 可执行步骤 (Execution)

**路径 A(先验证再辞):**

1. **确定目标方向**并写出"该方向的可售服务清单"。例:AI 标书代写、简历优化、PPT 制作。
2. **用现有资源铺获客通道**,不辞职、不投钱。例:把家人的手机号注册成各平台矩阵账号(小红书 / 快手 / 视频号 / 闲鱼 / 淘宝)。
3. **接单跑数据,周期 ≥ 1 个完整月**。记录:成交单数、客单价、总收入、交付耗时。
4. **核对阈值**:月收入是否 ≥ 10000 元?
   - 达到 → **判定通过**,可以辞职。
   - 未达到 → 进入路径 B。
   - 完成后:输出一张"月收入台账 + 是否达标结论"。
5. **注意边界**:验证期内主业的收入是安全垫,**不得**为了跑量而先辞职。

**路径 B(降薪换上限):**

1. **列出备选岗位**,对每个岗位填三栏:当前起薪 / 收入天花板 / 待积累的专业能力。
2. **筛选出"天花板高 + 有积累性"的岗位**,剔除"无能力积累"的岗位(判据:干三年和干一天的区别大不大)。
3. **计算降薪幅度**:新岗位起薪是否在原收入 70% 以内(即降幅 ≤ 30%)?
   - 是 → **判定通过**,可以转岗。
   - 否 → 不转,回到路径 A 继续用业余时间跑。
4. **设定观察期(建议 12 个月)**,到期复核:目标岗位的核心技能是否真的有积累、收入是否开始向上走。
   - 完成后:输出"岗位对比表 + 降薪幅度计算 + 观察期结论"。

**停止条件**:两条路径的判定结论均已给出;或用户明确表示不打算改变现状。

## B — 边界 (Boundary) ★

### 不要在以下情况使用此 skill

- **用户已有成熟技能、只是在纠结要不要换赛道**：应直接用本能力的路径 A，不要回到 `sheng-cun-ji-neng` 重新学技能。
- **用户问的是具体行业/岗位细节**：属于 `kan-guang-gao` / `da-gong-qi-bu` 的范围。
- **存在不可逆损失的场景**（辞职后失去编制、失去落户资格、家庭唯一收入来源）：不适用"先辞再试"的读法，只能走路径 A。
- **时间窗口极短的确定性机会**：跑阈值需要至少一个月，来不及。

### 作者在书中警告的失败模式

- **裸辞赌一把**（ce24/ce25）：用"我迷茫""我有勇气"替代收入验证。
- **用"上限高"当借口**：没有积累性的岗位，降薪换过去也只是换了个更累的地方。
- **副业收入来自平台红利**：跑通的是红利不是能力，月入一万是假信号。

### 作者的盲点 / 时代局限

- **"月入一万"是特定人群的具体数字，不是普适公式**：正确用法是换算成"该城市该生活水平下的可覆盖生活成本 + 20% 缓冲"。
- **"上限高 / 有积累性"没有量化标准**：使用者需自己补充判据（技能能否跨公司复用？是否随时间增值？）。
- **平台合规风险**：视频 105 中的"用家人账号做矩阵"涉及平台一人一号/实名认证规则，存在封号与违规风险，不构成本能力推荐的做法。
- **"降薪 30% 很痛苦"是必要条件而非缺陷**：主播在视频 030 中明确承认这条路径"短期之内一定会让你很痛苦"。

### 容易混淆的邻近方法论

- **FIRE / 财务自由**：讲被动收入，本能力讲能力验证。
- **"追随热情"**：讲感受，本能力讲数字。
- **"机会成本"分析**：讲取舍，本能力讲阈值门槛。
