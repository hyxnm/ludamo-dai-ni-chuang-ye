# 鲁大魔带你创业

> 鲁大魔草根创业与生存方法论的完整能力入口，覆盖 **23 个能力单元**。

从「没资源怎么起步」「要不要辞职转行」，到「怎么找行业/项目」「怎么低成本验证想法」，每个问题都给出**可执行步骤**与**判停条件**。

## 能力地图（23 个能力单元）

**认知与判断**

- 逻辑思维链（数据 → 秩序 → 逻辑 → 决策 → 工具）
- 看广告倒推（找行业 / 找岗位 / 找项目）
- 换不到钱的人的五特征自检
- 刺客式调研（以买家身份摸透一个具体标的）

**生存与起步**

- 生存技能优先（技能的判定标准是能否换到钱）
- 打工起步法（先去同行那里打工把流程摸熟）
- 资源优先级（时间 + 体力 + 方法 ≫ 钱）
- 辞职 / 转型决策阈值
- 求职避坑与面试实战

**验证与落地**

- 最小实验体（风险只能靠缩小实验体降低）
- 创业六步流程与出场顺序（不可跳步）
- 需求倒推法（从需求向下推演）
- 四个基本点（显性 / 具象化 / 可量化指标 / 可执行）
- 避坑优先法（先看前辈怎么死的）

**定价与增长**

- 性价比与供应链 / 定价三角
- 第二增长曲线与生态位选择
- 流量匹配法则

**人才与区域**

- 人才优先与区域围剿
- 区域聚焦与最小切口

**关系与防守**

- 处世三红线（亲人 / 朋友 / 合伙人）
- 李鬼矩阵打法（品牌矩阵与流量拦截）

**心态与沉淀**

- 逆袭觉醒（对抗迷茫 / 失败 / 短板 / 质疑）
- 工具化沉淀（把一项能力做成可复制的载体）

完整路由表见 [`SKILL.md`](SKILL.md)。

> 部分能力卡在 `SUPPLEMENT_LOG.md` 中标注了证据等级与合规提示，其中 3 张（李鬼矩阵、逆袭觉醒、工具化沉淀）带风险或低证据标记，使用时请留意卡内说明。

## 使用方式

将整个目录放入技能的加载路径（如 `~/.workbuddy/skills/`），按 [`SKILL.md`](SKILL.md) 路由表加载对应能力卡。

也可通过 SkillHub 安装：

```bash
skillhub install ludamo-dai-ni-chuang-ye --namespace user_806b1075
```

### 可选：飞书同步

`scripts/feishu_sync.py` 把已产出的清单/归档推到飞书群：

```bash
pip install requests
cp scripts/config.example.json scripts/config.json   # 填入你的机器人 webhook
python scripts/feishu_sync.py <文件路径> --mode task
```

> `config.json` 已加入 `.gitignore`，不会被提交。

## 适用边界

**不适用**：

- 具体行业的专业技术与操作细节
- 投资理财、股票基金、加密资产等金融建议
- 法律、税务、合规、医疗等需持牌专业人士判断的问题
- 已在稳定运营中的企业的日常管理、财务核算与人事纠纷

> 本包内容为对公开内容的方法论提炼，书中相关表述多为主播单方观点，已就低可信度条目在 `SUPPLEMENT_LOG.md` 中标注证据等级。使用请自行判断。
